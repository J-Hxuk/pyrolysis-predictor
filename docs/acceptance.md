# 데이터 확보 전 통합 수용 점검 (작업 24)

이 문서는 실제 연구 데이터 없이 **합성 규격으로 점검한 초기 기능**의 수용 기준과
실행 결과를 연결한다. 가상 기능 점검 완료이며 실제 연구 성능·공개 배포 완료가
아니다. 실제 적용·배포는 작업 25–32 에서 수행한다.

## 자동 통합 점검 — `tests/test_end_to_end.py`

서로 다른 두 합성 규격으로 전체 흐름을 연결한다. 두 규격은 입력 ID·대상·단위가
다르다 (코드 수정 없이 설정으로만 바뀜을 확인).

- `tests/fixtures/synthetic_spec_a.yaml` — 회귀(wt%) + 검출 분류.
- `tests/fixtures/synthetic_spec_b.yaml` — 서로 다른 단위의 회귀 2개(wt%, m2/g)
  + 미지원(비활성) 분류 대상.

| 수용 항목 | 점검 내용 | 결과 |
|---|---|---|
| 전체 흐름 연결 | 학습 → 완전 묶음 export → 다시 읽기 → 단일·일괄 예측 → 수치형 순위 | ✅ 통과 |
| 저장 전후 재현 | export 시 저장 전후 예측 허용 오차(1e-6) 검사, 재읽기 후 단일=일괄 | ✅ 통과 |
| 규격 교체 | A↔B 로 입력 ID·대상·단위가 코드 수정 없이 바뀜 | ✅ 통과 |
| 미지원+활성 공존 | 비활성 대상은 manifest 에 사유만, 예측·순위에서 제외 | ✅ 통과 |
| 부분 목표 결측 | 한 대상만 앞 10행 결측 시 대상별 가용 행이 다르게 보존 | ✅ 통과 |
| 동시 양성 분류 | 두 검출 대상이 같은 행에서 함께 양성 가능 (상호 배타 아님) | ✅ 통과 |
| 열 순서 변경 | 규격 ID 기반 읽기로 열 순서를 바꿔도 같은 정규화 입력 표 | ✅ 통과 |
| 마지막 행 오류 | 마지막 행 필수 결측 시 모델 미호출·전체 실패·순위 없음 | ✅ 통과 |
| 출력 제약 위반 | 비음수 제약 위반 유도 시 전체 요청 실패 | ✅ 통과 |
| 묶음 훼손 | contract.json 훼손·필수 파일 누락을 로딩 전에 거부 | ✅ 통과 |
| 환경 불일치 | environment.json 의 라이브러리 버전 불일치를 check-bundle 이 감지 | ✅ 통과 |
| 입력 변경 무효화 | 입력 변경 후 이전 결과가 남지 않음 | ✅ 통과 |
| 두 세션 분리 | 독립 세션의 결과가 섞이지 않고, 한쪽 초기화가 다른쪽에 영향 없음 | ✅ 통과 |

실행:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_end_to_end.py -q
```

통합 점검은 기존 모듈 테스트(값 검증·순위·세션 등)를 반복해서 늘리는 대신,
모듈을 **조합했을 때 남는 위험**(규격 교체, 저장 전후 재현, 미지원 공존, 전체
실패 시 부분 결과·순위 미노출)을 확인한다.

## 수동·환경 의존 점검 — 미완료 기록

아래 항목은 실행 환경(Linux, 브라우저)이 있어야 확인할 수 있다. 환경이 없으면
여기에 **미완료**로 남기고 해당 작업에서 확인한다.

| 항목 | 상태 | 확인 예정 |
|---|---|---|
| Linux(Ubuntu 22.04)에서 고정 의존성 설치 | ⬜ 미완료 | 작업 24 환경 확보 시 / 작업 29 |
| Windows 생성 합성 묶음을 Linux 에서 읽어 예측 | ⬜ 미완료 | 작업 29 |
| 로컬 브라우저에서 한국어 화면·초기화 동작 | ⬜ 미완료 | 로컬 Streamlit 실행 시 |
| 결과 다운로드·복사 내보내기 차단 확인 | ⬜ 미완료 | 로컬 Streamlit 실행 시 (config: disableDataExport) |
| 두 브라우저 세션 분리 (실제 UI) | ⬜ 미완료 | 로컬 Streamlit 실행 시 |

> 코드 수준의 세션 분리·내보내기 차단 설정(`client.disableDataExport=true`,
> `server.enableStaticServing=false`)은 작업 17 에서 생성·검증했고, 세션 분리
> 로직은 위 자동 점검에서 확인했다. 실제 브라우저 동작 확인만 환경 의존으로 남는다.

## 완료 판정

- 적용되는 초기 기능(작업 1–23 중 구현 대상)의 수용 기준과 실행 결과가
  위 표로 연결되어 있다.
- 조건부 확장(작업 33–35)은 채택하지 않았으므로 이 점검 범위에서 제외한다.
- 환경 의존 항목은 미완료로 명시했다. 이들을 확인하기 전에는 실제 공개 배포
  완료로 표시하지 않는다 (작업 29·32).
- 가상 기능 점검 완료는 실제 연구 성능·공개 배포 완료를 뜻하지 않는다.
