# v15 학습·검증 계약: 최종 연구목표 고정

**연구목표:** 사용자가 초기 바이오매스를 자유 입력하면, 원료 조성(확보 시)과 제조공정 후보 및 목표 오염물질/흡착조건을 고려해 실측 문헌의 적용범위 안에서 **흡착량/제거율을 예측하고 유망한 제조방법을 제안**한다. 단순한 바이오매스 이름만으로 원소조성을 추론하지 않는다.

## 데이터셋 경계
- `03_Stage2_QE_Core_97.csv`: 유일한 Stage2 탐색적 experimental-uptake 핵심 모델 데이터. 97행, 25 DOI. 원문 `qe` 수치 대조 기록 존재하나 모든 실험이 엄격한 평형을 만족한다고 주장 불가.
- `04_QEXP_Kinetic_Optional_6.csv`: Xian 2018 kinetic Table qexp 실험값. 별도 후보/민감도 분석으로만. 명확한 평형 판정 전 핵심 97에 합치지 않는다.
- `05_QT_120min_Separate_32.csv`: Wang 2020 고정 120분의 time-dependent uptake. qe로 이름 변경 불가.
- `06_Removal_Separate_16.csv`: Chen 2022 원문 보고 제거율(%). 동일 실험조건하 16개 공정 조합의 유망조건 추천 테스트에 사용.
- `07_QE_Derived_From_Removal_16_DO_NOT_DOUBLE_COUNT.csv`: 물질수지 유도값, **기존 16 제거율의 동일 관측**. 새 독립 실측 QE 16개로 추가하지 않는다. `C0=100 mg/L`, `D=10 g/L`에서 물질수지 유도. pH는 원문 미확인 -> 비워둔다.
- `08_Langmuir_Qmax_Fitted_Separate_32.csv`: 흡착등온식 피팅 최대용량. qe/qexp/qt와 절대 혼합하지 않음.
- v14 Jaffari 3,757/1,518은 **원문 출처 DOI 누락, 중복, 다른 오염물질, 음수/물리 QA 이슈**로 미병합. 외부 모델 설계 참고만.
- 제조공정 복원: Stage2 97행 중 49행에서 활성화/개질 표기 후보를 확인했으나, 일부는 구버전 자료의 원문 원료/활성화 컬럼이므로 **제조공정화학 명세 정규화 전에는 모델용 확정 agent가 아니다**. 60개 시료에 원문 제조방법 텍스트 추적을 보존.

## A/B/C/D 공정한 모델 비교
- A = 목표 오염물질·초기농도·pH·흡착제 투입량·흡착온도·접촉시간 → qe.
- B = A + **초기 바이오매스 원료 특성/원료명** + 공정단계별 열분해·활성화·개질 변수 → qe. 사용자 목적의 직접 모델.
- C = B + **실측** BET/TPV (상한 비교/참고용; 사용자 제조조건만으로는 해당 값 모름).
- D = B + **Stage1이 독립 예측**한 BET/TPV (End-to-End 목표). Stage1 해당 제조공정 route 승인 및 동일 DOI 누출 통제 이전에는 사용 금지.
- **raw feedstock 조성**만 B/C/D 후보로 사용. `BIOCHAR_POST_PYROLYSIS` 원소조성은 초기 원료 조성으로 대체 금지.
- DOI, material_id, sample_id, 실험계열ID, 물질수지상한, 측정/검증 플래그, source URL, qmax, 제거율 target 값은 어떤 모델에도 입력하지 말 것.
- 학습 전 feature selection/결측 대체/스케일링/범주 인코딩은 **학습 fold 안에서 fit**.
- 특정 feature의 결측이 심하면 '실측 원료 조성 모델'과 '원료명/공정 분류 모델'을 구분해 비교. 원소조성 예측 모델을 구현했다고 주장할 수 없음.

## 검증 설계
1. **DOI 그룹 분할**: 같은 논문 출처 모든 시료와 흡착실험을 같은 fold로. 반복조건/동일 시료 공유 방지. Leave-One-DOI-Out 및 GroupKFold.
2. **원료 외삽 검증**: Leave-One-Feedstock-Out. 원료명 표기의 동의어를 사람이 검토해 그룹을 정제. 조성 기반 미학습 원료 예측 신뢰도 미보장.
3. **추천 검증**: Chen 2022의 16개 제조조건, Cd(II), 고정 C0/D/T/t에 대해 조건 홀드아웃에서 rank correlation, MAE(%p), best-observed ranking, top-1 / top-3 regret. 같은 16행을 전체 학습한 뒤 '예측 최적'을 검증 성능이라고 보고 금지. 16개 조합은 완전요인 64조합이 아닌 직교배열.
4. **물리성**: 예측 qe는 0≤qe≤C0/dose, 제거율 0–100%; 미확인 또는 이상한 단위에 대해 clipping으로 오류를 은폐하지 말고 위반율과 제약 후 성능을 모두 보고.
5. **교차 Stage1 누출**: Stage2 평가 DOI를 Stage1 v60 모델이 이미 학습한 경우 D의 입력은 fold별 Stage1 재학습·OOF 예측이 필요. v60 고정 artifact를 그대로 통합 holdout에 사용 금지.
6. 원문 검증의 마지막 단계는 종료. **모델 학습 중 실제 오류가 발견된 행만 DOI 원문 재검증**.
