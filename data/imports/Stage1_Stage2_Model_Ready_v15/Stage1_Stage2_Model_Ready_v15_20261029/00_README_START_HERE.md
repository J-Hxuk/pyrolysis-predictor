## 추천 입력의 핵심 의미
`feedstock_raw`는 사람이 입력하는 자연어 명칭의 **출처 기록/검색 단서**이지 예측 가능한 원료 조성을 뜻하지 않는다. 원료 조성은 **열분해 이전에 측정된 것만** raw_*에 둔다. 원료의 원소/공업분석값은 매우 희소하고 기준(daf/dry/wt%)도 섞여 있어 검증 없이 바로 채택하지 않는다. 열분해 후 C/H/O/N은 오직 물성·원문 근거로 남기고 원료 조성에 섞지 않는다.

## 단계적 개발 관점
우리가 실제 구현해야 하는 기능은 **자연어 바이오매스 입력 → 가능한 원료 특성 확인 → 제조조건 후보 생성 → A/B/C 비교 및 (나중에) Stage1 예측 물성 지원 D → 목표 오염물질에 대한 흡착량/제거율·적용범위 → 유망 제조조건** 이다. Stage1 v60은 초기 원료 C/H/O 분석을 현재 실제 특징으로 사용하지 않음.

**학습 가능 데이터와 엄격한 평형 승인 데이터는 같지 않다.** 현재 97행의 target은 exploratory reported uptake; 엄격한 qe 최종 승인 0행, Stage1 v60 직접 예측 연결 승인은 0행이다.
