# 파일 정리 원칙 (v42)

- **자동 이동·삭제 없음.** 연구용 실험 파일을 지우기 전에 DOI 원문 근거와 테스트 의존성을 점검.
- `학술대회_Archive_20261030`: 설치가 끝난 버전별 패치 ZIP, 오래된 설치 안내, 로그와 재생성 가능한 시각화의 **보관 장소**. 한 번에 전체 이동하지 말고 새 통합 기준본 검증 뒤 점진 이동.
- **항상 유지:** `pyrolysis/`, `scripts/`, `tests/`, `data/imports/`의 검증 추출본과 SHA256, `deployment/active.json`, 활성 모델, `reports/v40_new9`와 `reports/v42_physics`의 DOI OOF 결과, 논문 원문 PDF의 적어도 하나의 외부 백업.
- v15/v41/v60 ZIP 이름이 테스트에 등장한 과거 의존성 문제를 해결하지 않은 채 원본 추출본/ZIP을 삭제하거나 경로 변경하지 말 것.
- 프로젝트 용량이 커지면 캐시(`__pycache__`, `.pytest_cache`)부터 진단하고, 원본 논문과 거대 원본 백업은 체크섬·2중 백업·테스트 검증 후 외부 보관을 고려.
- v43~v45에서는 연구 통합 기준본을 만들어 '새 기준본+현 버전 패치'와 '이전 증분 패치 아카이브'를 분리하는 것을 권고.
