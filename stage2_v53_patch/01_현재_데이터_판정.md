# v52+vNext10 현재 확인된 판정
- v52 보고 기준 Stage2 140→164행, DOI 33; Stage1 417→421행. 활성 모델 승격 없음.
- 2020 Zhao et al. DOI 10.3390/en13133498 자료 24행(제조온도 BC300/400/500/600 × Cu/Zn × dose 1/5/20 g/L).
- 5 g/L 8행만 Table 3 qe,exp source-verified strict-qe; 1/20 g/L 16행은 평형 여부 미확인 24h observation, 민감도 자료.
- vNext10 8행은 위 5g/L 8행과 동일 계열이므로 추가 중복 학습 금지.
- 교차 출처 2017 DOI 10.3390/en10091293에서 Stage1 물성 활용이 보고되어 외부 holdout 아님, 물성/동일 배치 확인 필요.
- 대나무 SI는 24h qt, dose 미확인으로 strict qe 미승인.
- 실제 140행/164행 CSV와 v52 모델이 현재 패치 안에 없으므로, 추가 성능 재계산/최종 재학습은 이 패키지 제작으로 수행하지 않음.
