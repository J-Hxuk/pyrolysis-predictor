# v28 제조조건 순위 식별 가능성 감사 + 사용자 메뉴 정리

2026-10-30 · 기존 v27 **DOI 그룹 홀드아웃 원시 예측** 재분석. **추가 학습·배포모델 변경 없음.**

## 결론

v27의 Model B 제조조건 순위 비교군 12개 중 평가 가능한 비교군은 11개(7 DOI, 실측 차이가 있는 30쌍)였다. **열분해온도를 실제로 다르게 설정한 비교군은 0개**였다. 온도가 기재된 비교군 10개에서는 각 비교군 내부 온도가 동일했고, 나머지 2개는 온도가 전부 미보고였다(그중 한 그룹은 실측값 동률로 순위 평가 제외).

즉, 기존에 관측한 비교군별 평균 순위 일치율 **0.8712는 열분해온도 최적화 성능을 보여주는 결과가 아니다.** 주로 제조경로, 후처리, 개질 여부 등의 상대적인 차이를 비교한 결과다.

## 데이터 계약 손실

- 평가 가능한 **11개 비교군 중 4개**에서 서로 다른 관측 시료의 제조 입력 벡터가 겹쳤다.
- 실측값에 차이가 있는 전체 30쌍 중 **6쌍은 모델에 주어진 제조조건 입력이 완전히 같았다.** 따라서 해당 쌍의 성능 차이는 현재 입력으로 식별 불가능하다.
- 전체 30쌍 중 **10쌍은 Model B 원시 예측값도 동률**이었다.
- 제조입력 벡터가 같다는 것은 *실제 제조공정이 동일하다*는 뜻이 아니다. 개질제 종류·투입량, 제조경로 세부정보의 결측/정규화 손실을 의미할 수 있다.

## 방법

기존 `reports/v27_recommendation_audit/stage2_heldout_doi_predictions.csv`의 33행 OOF 예측을 그대로 사용하고, Phase 8 Core 98행의 제조 입력 계약과 `observation_id`로 일대일 조인했다. DOI/원료/오염물질/흡착조건이 동일한 비교군에서 제조변수의 변화를 확인했다. 실측값은 그룹 정의와 모델 입력에 사용하지 않았으며, 순위 평가를 위해서만 사용했다. 원시 qe를 clipping하지 않았고 새 모델 학습도 없다.

## 연구 및 개발상의 함의

1. **열분해온도 최적화 주장 보류.** 현재 검증은 제조경로 및 개질조건의 일부 상대적 비교에 국한된다.
2. **원료·제조조건 입력 데이터 계약 개선:** 제조단계, 개질제 이름·용량/혼합비, 2차 온도/유지시간을 별도 필드로 명확히 수집하고, 실제 정보가 누락된 사례를 구별한다.
3. 서로 다른 제조시료에 같은 입력이 배정되는 경우, 모델 점수만으로 단일 최적 시료를 고르지 않는다.
4. 새 논문에서 열분해온도 3수준 이상, 흡착조건 고정, 소재별 실측 qe 및 BET/TPV가 연결된 자료를 확보한 뒤 다시 DOI 홀드아웃 평가한다.
5. 순위 일치율은 높은 듯해도 v27에서는 **원시 물질수지 위반 17/33**이므로 사용자용 정량 추천은 제한한다.

## 앱 UI 정리

사이드바를 **4개 주요 기능**으로 정리했다: 흡착성능 예측, 제조조건 탐색, BET 물성 예측, 데이터·모델 검증. 기존 수동 온도 스윕은 제조조건 탐색의 하위 메뉴로, 개요·Phase 8·신규 문헌 조회는 데이터·모델 검증 하위 메뉴로 이동했다. 기존 실험·데이터 기능은 삭제하지 않았다. v28 연구 결론은 제조조건 탐색 및 검증 페이지에 경고/설명으로 연결했다.

## 검증 경계

이번 평가는 **이미 반복적으로 살펴본 코호트의 사후 감사**로, 외부 독립 재현 성능·원료 일반화·열분해온도 최적화 정확도를 보증하지 않는다. Streamlit GUI 실렌더링 및 Windows의 모델 호환성은 현 환경에서 미실행. `py_compile`, 정적 UI 계약 테스트 및 v26/v27/v28 비UI 회귀 테스트만 수행한다.
