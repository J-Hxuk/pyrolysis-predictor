# v140 — Manufacturing RF in unified simulator
- Stage 1 and Stage 2 remain v139: ten-feature Poisson HGB and equal-weight KNN + weighted Extra Trees. Neither estimator nor their training data is changed.
- Manufacturing RF is separate: 160 trees, depth 3, leaf size 2, max_features .9, random_state 42. Target is observed removal percentage centered within each training manufacturing panel. Sample weight = 1/(sqrt(panels per DOI) * observations per panel), normalized.
- The 59-row snapshot comprises the exact manufacturing-panel rows from Stage2_v57_188_both_RESEARCH_NOT_ACTIVE.csv in the user-supplied final project archive, preserving original row ordering and v60 archived DOI folds. The original 188-row source is not present in GitHub. The snapshot joins 59 source records from reports/v60_separate_effects/all188_doi_oof_predictions.csv to the original panel-constant manufacturing features; no synthetic targets. 15 panels / 9 DOI. Original rank fit uses all 59, including Zn(II); matched comparison excludes the 3 Zn panels because Stage 2 does not support Zn(II).
- Local reproduction (scikit-learn 1.8.0): fixed-fold rank prediction max absolute difference vs v139 Figure 7 OOF reference = 3.55e-15; matched 12 panels: 5/12 correct unique top candidate, mean worst-tie regret 2.7808333333 mg/g. This is retrospective development evaluation; bootstrap intervals include zero, no proven superiority.
- UI compares absolute uptake prediction and relative RF rank, retains ties, excludes temperatures outside rank training min/max (250–900 C), requires three in-range candidates. UI supports only unmodified single-stage pyrolysis, the rank/Stage 2 overlap (Cd/Cu/Pb), and flags unfamiliar feedstock/pollutant combinations, atmosphere and numeric ranges. Not a measured optimum. The score is centered removal percentage points, NOT removal percentage or capacity. Composition and adsorption-condition sensitivity are not part of RF.
- Test: python -m pytest tests/test_manufacturing_rank_v140.py -q. Local model-only parity and gate checks passed; complete Streamlit UI runtime and pinned 1.5.2 environment not executed.
