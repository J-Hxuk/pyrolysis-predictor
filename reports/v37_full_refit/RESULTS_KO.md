# Biochar v37 — 실시간 UI 및 전체 호환 데이터 재학습 (연구용)

작성 기준: 2026-10-30. 이 패치는 v36을 설치한 프로젝트에 적용한다. 기존 Stage 1 v60·Stage 2 v15 활성 모델은 변경하지 않는다.

## 1. 질문에 대한 기술적 결론

- 기존 모델이 새 논문을 잘 예측하지 못한다는 이유로 논문 자체를 버리는 것은 타당하지 않다. 출처가 확인되고 타깃 정의가 일치하면 새 모델의 **연구용 통합학습 후보**로 보존하고, 성능 비교는 독립 DOI 단위로 평가한다.
- 그러나 `qt(240 min)`, `qmax(Langmuir)`, 단일금속 `reported qe`, 다성분 용액 실험, 독립 2차 판독이 없는 그래프 근삿값은 같은 지도학습 타깃이 아니다. 이들을 무차별 합치면 학습행만 늘고 종속변수 의미가 훼손된다.
- **v37은 Stage1 333개 물성 시료 후보 및 Stage2 113개 reported uptake 행으로 실제 새 모델을 학습한 실험**이다. QA 단계의 후보를 사용한 *research-only* 결과이므로 기존 배포 성능이나 독립 외부 일반화 성능을 대체하지 않는다.

## 3. Stage 2: 113행, DOI GroupKFold 5분할 (고정 하이퍼파라미터)

| 모델 | 알고리즘 | R² | MAE (mg/g) | 원시 물질수지 위반 |
|---|---|---:|---:|---:|
| A | Dummy | -0.047 | 39.05 | 54/113 |
| A | Ridge | -0.076 | 34.16 | 32/113 |
| A | RandomForest | 0.354 | 29.56 | 51/113 |
| **A** | **XGBoost** | **0.685** | **19.80** | **34/113** |
| B | Ridge | 0.236 | 33.02 | 48/113 |
| B | RandomForest | 0.291 | 31.60 | 54/113 |
| **B** | **XGBoost** | **0.677** | **19.74** | **43/113** |

- XGBoost의 동일 검증 예측에서 `MAE(B) - MAE(A) = -0.058 mg/g`. DOI-cluster bootstrap 95% CI **[-3.33, +3.68] mg/g**. 제조조건을 더 넣은 모델이 더 좋다고 주장할 근거가 없다.
- 원시 물리제약 위반율은 A 30.1%, B 38.1%. clipping은 참고값으로만 별도 보고한다. clipping에 따른 MAE 감소를 물리모델의 학습 성능 향상으로 오해하면 안 된다.
- 위 평가는 **고정 초매개변수 GroupKFold 5분할**이다. v16의 Nested CV, v34의 기존 98행에 대한 같은 DOI LODO 전후 비교와 **평가 분할이 다르므로 수치를 나란히 놓고 모델 개선이라 주장할 수 없다**.
- 과거 v34의 *동일 98행 홀드아웃* 비교에서는 113행 학습으로 A/B 예측오차가 개선되지 않았다. 따라서 새 모델은 정식 교체 대상이 아니다.

- 새로운 제조정보 기반 연구용 모델만 비교했다. 이 실험에 원료의 **열분해 후 조성은 입력으로 사용하지 않았다**. 열분해 전 원료 조성의 분석기준 검증이 부족하여 이번 전면 재학습의 필수변수로 추가하지 않았다.
- v60의 feature engineering과 데이터·분할 규약은 다르므로 이 R²를 v60 모델의 성능 향상으로 해석할 수 없다.
- 서로 다른 제조 경로를 하나의 모델로 학습한 데이터 이질성, DOI 편중, 물성 분포의 긴 꼬리는 여전히 큰 불확실성 요인이다.

## 5. 실시간 인터페이스

- pH, 초기농도, 투입량, 접촉시간, 흡착온도를 **슬라이더**로 조절하면 버튼을 다시 클릭하지 않고 결과를 재추론한다.
- 원시 qe/원시 제거율 및 Model A/B 곡선을 표시한다. 점선은 물질수지 상한이며 원시 위반을 숨기지 않는다.
- '현재 조건을 비교 기준으로 저장'하면 변경 전후 qe 차이를 추적한다.
- 그래프는 한 번에 하나의 변수를 변화시키고 다른 조건을 고정한다. 실험 데이터가 아니며 보간/외삽, 인과효과 또는 전역 최적 제조조건을 보증하지 않는다.
- 미학습 원료의 Model B 추천은 그대로 차단하고, Model A 원료 비특이적인 탐색적 예측만 제공한다.
- 화면에서 사용하는 모델은 **기존 활성 모델**이다. `deployment/research_v37_NOT_ACTIVE/`의 모델은 자동 로드·배포하지 않는다.

## 6. 재현성과 제한

`python -m scripts.build_v37_full_refit --root .` 명령으로 새로운 DOI 그룹 CV와 연구용 모델을 로컬 환경에서 재생성한다.

이번 환경: Python 3.13, scikit-learn 1.8.0, XGBoost 3.1.3. 생성된 `joblib` 파일을 이전 Windows `.venv`에 그대로 로드하면 버전 불일치가 생길 수 있으므로, 연구용 파일은 자동 활성화 금지. 코드 및 산출 CSV·JSON을 함께 제공한다.

신규 단위 테스트 **9개 통과**. 기존 v34/v35/v36 분석 테스트 **28개 통과**. 실제 Windows Streamlit 렌더링은 이 환경에 Streamlit이 설치되지 않아 미확인. 전체 프로젝트 회귀 테스트 미실행.
