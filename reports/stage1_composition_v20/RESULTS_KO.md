# Stage 1 v20 — 연구용 조성기반 BET 추론 (v19에 추가되는 신규 화면)

## 완료한 것

- `eval37/base.csv`의 **비활성화 바이오매스 BET 데이터 182행, provenance DOI 24그룹**으로 실험용 RandomForest 2종을 전체 적합했다.
- 입력 A: 열분해온도·유지시간·승온속도 + 원료 공업분석 3종(VM/Ash/FC, **dry basis**).
- 입력 B: A + 원료 원소분석 4종(C/H/N/O, **dry ash-free basis**).
- 모델을 `deployment/experimental_stage1_bet/experimental_composition_bet_v20.json`으로 저장했다. 모델 트리를 JSON으로 내보내 원래 `scikit-learn` RandomForest의 추론과 부동소수점 허용오차 이내 일치함을 시험했다. 이 JSON은 pickle/joblib이 아니어서 scikit-learn 저장/실행 버전 변경에 따른 deserialize 위험을 줄인다.
- Stage 2 앱의 **F. Experimental BET (Stage 1)** 탭에서 모델을 읽어 추정 BET를 보여주도록 했다. 전체 모델의 4개 조성변수가 없으면 임의 보충하지 않는다. 원소분석 4개가 전부 없고 공업분석 3개가 있으면 공업분석 전용 모델을 사용한다.
- 원료명은 어떤 모델에도 입력되지 않는다. 같은 조성·열분해조건을 주면 원료명이 달라도 같은 결과가 나오는 것이 정상이다. 따라서 미학습 원료 특성을 이름만으로 반영했다고 주장하지 않는다.
- 입력 조성이 다른 basis이거나, 활성화·개질·다단계 공정이거나, 개별 변수의 학습 최솟값·최댓값을 벗어나면 수치 계산을 차단한다.

## 검증 결과의 정확한 범위

기존 v18에서 **같은 182행과 같은 DOI LODO**로 비교한 RandomForest 결과:

| 입력 | R² (OOF) | MAE (m²/g) |
|---|---:|---:|
| 공정조건만 | −0.460 | 97.75 |
| 공정 + 공업분석 | 0.253 | 69.52 |
| 공정 + 전체 조성 | 0.257 | 66.42 |

위 교차검증 결과는 v20 전체자료 적합 모델을 새 데이터에서 검증한 수치가 아니다. 여러 Feature Set을 살핀 뒤 결과가 더 좋았던 모델 2종을 선택했으므로 **모델 선택 독립성까지 충족하는 잠금 외부 테스트는 없다**. R²와 MAE는 연구용 참고 성능일 뿐 개별 예측의 신뢰구간이 아니다. 논문 출처 원문 재검증 수준에도 제한이 있다.

## 적용 불가 / 명시적 미완성

- 이 모델은 **BET만** 출력한다. TPV와 qe는 출력하지 않는다.
- Stage 1 v60의 기존 모델은 변경·재학습하지 않는다. Stage 2의 A/B/C/D와 자동 연결하지 않는다.
- Stage 2의 최적 제조조건 추천기와 연결하지 않는다. 관측되지 않은 원료의 외삽 정확도가 확인된 것은 아니다.
- 사용자가 제공한 원료의 분석값은 실제 **열분해 전 시료**여야 한다. 바이오차(열분해 후)의 원소분석값을 원료 값으로 넣으면 안 된다.
- 기존 v18 평가 데이터의 비활성화 바이오매스 조합은 제한적이므로 활성화 소재·광미 혼합·2차 처리에 적용하지 않는다.

## 테스트

- 실험용 모델 export→추론 수치 일치, 누락·basis·공정 범위 차단, 대상/feature 계약 관련 신규 4개 테스트 통과.
- 기존 v18 및 v19 관련 테스트를 포함한 26개 테스트 통과.
- Stage2 v16 8개 통과. Stage2 v15의 2개 테스트는 이 실행 환경에 Streamlit 부재·CatBoost/sklearn 호환성 문제로 실패했다. **전체 회귀 테스트 통과를 주장하지 않는다.**
- 실제 Windows Streamlit 브라우저 렌더링 테스트는 수행하지 못했다.

## 사용

1. v19 적용된 프로젝트에 v20 패치를 덮어쓴다. v60과 기존 모델, 데이터, `.venv`는 변경하지 않는다.
2. `python -m pytest tests/test_stage1_bet_v20.py -q`를 실행한다.
3. `python -m streamlit run biochar_stage2_app.py`로 앱을 열어 사이드바 **F. Experimental BET (Stage 1)** 선택.
4. 열분해 전 원료 공업분석 VM, Ash, FC 3개와 열분해 3개 조건을 입력한다. 원소분석 C/H/N/O까지 있다면 분석기준 `dry ash-free (daf)`을 선택하고 입력한다. 출력 BET는 연구용이다.
5. 학습 재생성은 필요한 경우 `python -m scripts.train_stage1_bet_v20`을 실행한다. 설치 파일에는 이미 JSON 모델이 포함되므로 기본 사용에 재학습은 필요 없다.
