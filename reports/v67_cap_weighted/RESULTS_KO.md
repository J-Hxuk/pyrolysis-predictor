# v67 — cap 가중 손실 실험 (연구용, NOT ACTIVE)

**역할:** `RESEARCH_ONLY_NOT_ACTIVE`. 활성 배포 모델·원본 데이터·기존 리포트를 변경하지 않음.
**평가 시점:** 2026-10-31. 환경: Python 3.12.10, scikit-learn 1.5.2, XGBoost 2.1.3.

## 1. 가설과 설계

v65·v66 에서 분율 표적(`f = qe/cap`, `cap = C0/dose`)은 상한위반 0%와 전형적 DOI 개선을 보였지만,
소수 DOI 에서 최악 오차가 커졌다. v66 은 그 원인을 "cap 이 큰 샘플의 역변환 증폭"으로 추정했다.

`q_hat − q = cap × (f_hat − f)` 이므로, 분율 표적에 `sample_weight = cap^α` 를 주면 큰 cap 샘플의
분율 오차를 더 무겁게 학습한다. α=2 이면 학습 손실이 qe 공간 MSE 와 같아진다.

| 방식 | 내용 |
|---|---|
| BASELINE | qe 직접 학습 + 사후 clip (활성 방식) |
| CAPW_a0 | 가중 없음 (= v65 FRACTION) |
| CAPW_a0.5 / a1 / a2 | `w = cap^α`, 학습 fold 안에서 평균 1로 정규화 |
| NESTED_alpha | 외부 fold 마다 학습 DOI 안의 내부 GroupKFold(4)로 α 선택 → **사전 지정한 1차 비교** |

데이터(188행/36 DOI)·외부 분할(DOI GroupKFold 5)·피처(Model B + cap)·XGBoost 설정은 v65·v66 과 같다.
고정 α 4개는 같은 평가 OOF 를 공유하므로, 그중 최선을 고르는 것은 사후 선택이다.

## 5. 행 단위 진단 — 꼬리의 원인은 역변환 증폭이 아니었다

말뭉치 전체의 흡착 분율 `f_true` 는 중앙값 0.71, q10 0.17, q90 0.98 이고, cap 은 중앙값 40, 최대 500 이다.

**pone.0218114 (Ni(II), C0=100):** 실제 분율이 0.041, 0.071, 0.246 으로 말뭉치에서 매우 낮다. 두 행은
dose 0.2 g/L 로 cap=500 (말뭉치 최대값)이다. 분율 모델(a0)은 0.49~0.67 을 예측해 전형적 분율 쪽으로
끌려갔고, 이 차이에 cap 500 이 곱해졌다. BASELINE 도 0.27~0.74 에 해당하는 값을 예측해 틀렸지만 덜 틀렸다.

**psep.2017 (Cu(II), C0=1000, dose 6.67, cap=150):** 실제 분율이 0.92~0.98 로 매우 높다. 분율 모델은
0.36~0.68 로 과소예측했고, BASELINE 은 0.83~0.92 로 잘 맞혔다. C0 가 높으면 보통 제거율이 낮아지므로
분율 모델은 낮은 분율을 예측한 반면, qe 모델은 "C0 가 높으면 qe 가 크다"는 말뭉치 경향 덕분에 맞혔다.

두 DOI 는 방향이 반대다. 하나는 이례적으로 낮은 제거율, 다른 하나는 이례적으로 높은 제거율이다.
문제는 증폭 자체보다, **이 재료들의 특성이 입력 피처에 없어서** 분율 모델이 말뭉치 평균 제거율로
되돌아간다는 데 있다. 가중치는 어느 샘플을 더 맞출지만 바꿀 뿐, 없는 정보를 만들지 못한다.
v66 의 원인 추정("cap 큰 샘플의 역변환 증폭")은 일부만 맞았다.

## 6. 사전 지정한 1차 비교 — NESTED vs BASELINE

- 평균 MAE 이득 **−1.78 mg/g** (음수 = BASELINE 우세), DOI 부트스트랩 95% 구간 **[−6.86, +2.57]**.
- 유의한 차이는 없고, 점추정은 BASELINE 이 낫다.
- fold 별로 고른 α 는 1, 0, 0, 1, 2 로 일정하지 않았다. 내부 CV 의 α 간 MAE 차이(예: fold 1 에서
  20.16~20.36)가 잡음보다 작아 선택이 불안정했다. 꼬리 DOI 가 든 fold 에서 α=0 이 선택돼 NESTED 의
  꼬리 오차는 a0 와 같다.

사후 비교(참고): 어떤 고정 α 도 BASELINE 대비 유의한 MAE 이득이 없다. a0.5 가 가장 가깝다
(−0.08, [−4.96, +4.50]).

## 7. 결론

1. **가설은 기각한다.** cap 가중은 상한위반 0%를 유지하지만, 집계 MAE 로 BASELINE 을 이기지 못했고
   꼬리 DOI 도 BASELINE 수준으로 복구하지 못했다. 사전 지정한 NESTED 는 수치상 더 나빴다.
2. **일관된 상충은 남아 있다.** 분율 계열(특히 a1)은 전형적 DOI 지표(q75 34.8 → 19.6, R² 중앙값
   −1.31 → −0.31)가 좋고, BASELINE 은 최악 DOI 가 좋다. α 를 바꿔도 이 상충은 사라지지 않았다.
3. **188행에서 표적·손실 변환을 더 탐색하는 것은 효과가 작다.** v65~v67 세 실험이 같은 결론을 낸다.
   남은 오차는 피처에 없는 재료 특성에서 온다. 효과가 큰 수단은 데이터(이례적 조건을 가진 DOI 추가)와
   봉인 평가다.
4. 활성 모델은 그대로 둔다. 분율 계열을 다시 검토하려면, 지금 결과를 보고 고른 후보(예: CAPW_a1)를
   Stage 2 봉인 프로토콜에 **사전 등록**하고 봉인 세트로 한 번 평가해야 한다. 같은 188행에서 다시 고르면
   사후 선택이 반복될 뿐이다.
