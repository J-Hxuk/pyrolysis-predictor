# Stage2 v54 연구용 재학습 — 물리 제약 및 제조조건 순위 검증

**실행일:** 2026-10-31  
**범위:** v47 통합 프로젝트 + v53 재학습 모델과 원문 감사 + Chen16 기존 참고 데이터  
**배포 상태:** `RESEARCH_ONLY_NOT_ACTIVE`. 활성 모델, Stage1 모델, 승인 데이터는 변경하지 않음.

## 1. 데이터와 평가 계약

- v46 Stage2 기준 140행 / 32 DOI를 **공통 평가 집합**으로 고정한 DOI GroupKFold(5), 전처리 및 XGBoost 매 fold 재학습.
- 세 학습 조건: 기존 140행, 기존 140+Zhao2020 Table 3 실험 qe 8행, 기존 140+Zhao2020 24h 관측을 포함하는 24행.
- 마지막 164행은 **평형 판정이 미완인 16행**을 포함하므로 민감도 분석에만 사용.
- 추가 8행은 2020 DOI Table 3에서 실험 qe로 확인되었으나, **2017 물성 연결의 동일 배치 증거가 확정되지 않았으므로 최종 Stage2 적격 승인 아님.** 연구용 시나리오로만 사용.
- 기존 140행도 전부 strict qe가 아니므로 이하 결과는 strict-qe 단독 학습 성능이 아님.
- vNext11 신규 승인 학습 데이터는 0행; 기존 차나무 가지 5행을 자동 추가하지 않음.
- Stage1, Model C/D, Streamlit 활성 모델 및 원본 DB를 변경하지 않음.

## 2. 물리적 제약과 두 새로운 모델

질량수지의 상한은 `cap = C0_mg_L / dose_g_L` (mg/g)이다. 비교 대상:

1. `direct_clip`: 기존 v53 XGBoost로 qe를 회귀하고 사후에 `[0, cap]`으로 잘라냄. 사후 위반율 0은 **원 예측이 물리적으로 타당하다는 증거가 아님**.
2. `logit_fraction`: `(qe/cap)`을 `(0,1)`로 보정(학습용 변환 epsilon=1e-4)한 뒤 logit으로 회귀하고 `cap * sigmoid(z)`로 복원. 예측 출력이 구조적으로 범위 내.
3. `logistic_fraction`: XGBoost `reg:logistic`으로 qe/cap 비율 자체를 회귀하고 `cap * fraction`으로 출력. 예측 출력이 구조적으로 범위 내.

상한은 **비음수·투입농도·흡착제 투입량**을 이용한 물질수지 조건일 뿐, 오차나 이온 흡착 기작까지 자동으로 정당화하지 않는다.

### 동일한 140행 DOI GroupKFold 5 성능

| X 입력 | 학습 집합 | Direct+clip MAE | Logit MAE | Logistic MAE | Direct raw 상한초과 |
|---|---|---:|---:|---:|---:|
| A | 140 | **17.247** | 20.042 | 23.010 | 43/140 |
| A | 148 (140+8) | **17.190** | 20.609 | 21.524 | 41/140 |
| A | 164 (140+24) | **16.760** | 19.787 | 20.354 | 42/140 |
| B | 140 | **17.690** | 21.100 | 22.576 | 50/140 |
| B | 148 (140+8) | **17.643** | 21.899 | 22.458 | 46/140 |
| B | 164 (140+24) | **17.761** | 20.903 | 20.854 | 46/140 |

MAE 단위: mg/g. 두 fraction 모델은 모든 140개 OOF 예측에서 상·하한 위반 **0/140**. 기존 direct+clip도 사후 위반은 0/140이나 **사전 상한 위반 41–50/140**이다.

동일 fold의 DOI 단위 bootstrap 95% 신뢰구간을 2,000회 계산했다. `148행` A logit vs direct의 MAE 개선량은 **−3.419 mg/g**, CI **[−8.850, +0.588]**, B logit vs direct는 **−4.256 mg/g**, CI **[−11.801, +1.694]**다. 0 포함. 임의의 모델 선택 과정에 대해 중첩 CV를 수행한 것은 아니므로 성능 우월성을 주장하지 않는다.

**결론:** 물리 제약 이행은 검증됐지만, 현 데이터에서 예측 정확도가 오히려 악화됐다. **v54 배포 승격 금지.** 본 결과를 감추고 저오차 모델인 것처럼 소개하지 말 것.

## 3. 제조조건 추천: 비교 가능한 근거만 사용

### Zhao et al. (2020), 사과나무 가지, Cu(II)·Zn(II)

- DOI: https://doi.org/10.3390/en13133498
- 각 금속 제조온도 300/400/500/600°C의 **5 g/L 실험 qe 4개**로 2개 고정조건 내부 비교계열을 구성.
- Stage2 기준 140행만 학습하고 2020 DOI의 8행을 예측(테스트 DOI는 Stage2 학습에 없음). 그러나 역사적 Stage1에서 2017 물성 DOI가 노출돼 **완전 독립 외부 홀드아웃 아님**.
- Model A는 제조온도가 입력변수가 아니므로 각 계열 모두 동률: 순위평가 불가.
- **Model B direct:** Cu Spearman ρ=0.80, top1 regret **0.83 mg/g**; Zn ρ=0.80, top1 regret **1.12 mg/g**. 두 계열 모두 top3 regret 0.
- Model B logit fraction은 각각 ρ=0.40, top1 regret 2.14/3.42 mg/g.
- 자료 4점짜리 2계열만으로 추천 알고리즘을 검증했다고 주장하지 않음.

### Chen et al. (2022), 16개 제조조건 직교실험

- DOI: https://doi.org/10.1038/s41598-022-22714-y, *Scientific Reports* 12, 17714.
- 원문에 따라 **Cd(II)**, 옥수수대(Corn stover), **100 mg/L, 10 g/L, 25°C, 1440 min**, 제조조건별 제거율(%)을 비교. 논문은 700°C, 150분, 5°C/min 조건의 C16을 최고 제거율 **95.79%**로 보고.
- 16행의 초기 pH는 보존된 벤치마크 CSV에서 **NR**. 기본 예측은 학습 fold의 수치 중앙값으로 결측 대체한 가정하에서만 계산하며, pH=4/6/7은 *가상 민감도 분석*이지 실측값이 아님.
- 각 16행의 C0와 dose가 동일하므로 qe와 제거율의 **순위만** 서로 비교 가능. `reported_removal_pct`를 임의로 실측 qe 타깃으로 승격하지 않음.
- **Model B direct:** Spearman ρ=**0.842**, 예측 1위 C16, top1 regret **0.00 %p**.
- **Model B logistic fraction:** ρ=**0.793**, 예측 1위 C14, top1 regret **6.79 %p**.
- **Model B logit fraction:** ρ=**−0.088**, 예측 1위 C1, top1 regret **59.37 %p**.
- Model A는 온도·유지시간·승온속도가 입력이 아니고 나머지 시험조건이 일정하므로 16개 값 모두 **동률**. 임의의 파일 첫 행을 1위로 삼지 않고 지표는 NA.
- pH=4,6,7 가상 시나리오에서도 direct B는 1위 C16으로 유지됐으나, 미보고 pH·기타 잠재 변수의 검증은 여전히 불충분. 기존 역사적 Stage1 노출도 추가 확인 필요.
- Chen은 실험 내 제조조건 순위 참고자료이며, 새로운 원료·실험실·논문에 대한 **독립 외부 성능 보증이 아님**.

## 5. 연구 판단과 다음 작업

**이번 단계에서 직관적이지만 잘못된 결론은** "물리 제약을 추가하면 예측 성능도 좋아진다"는 것이다. 결과는 반대. 현 데이터에서는 직접 qe 모델의 post-hoc clipping이 더 낮은 MAE를 갖지만, 물리상한 초과 예측이 상당해 모델의 원예측을 그대로 실험 조건 추천에 활용하기 어렵다. 물리위반율과 오차를 별도로 관리해야 한다.

다음 개선은 (1) 엄격 평형 타깃만 남긴 실험 별도 민감도 분석, (2) 연구용 후보 내에서 nested DOI validation에 기반한 하이퍼파라미터 선택, (3) 유효한 내부 비교계열 확대, (4) 진정한 외부 DOI 및 미노출 신규 실험 확보 순서가 타당하다.
