# v31 — 왕겨 제조온도별 실험 마커 외부 DOI 도전 평가

**판정: Model B의 제조온도 Top-1 추천은 2개 오염물질 계열 모두 실패. 원시 예측의 절반(3/6)은 물질수지 제약을 위반한다. 모델 교체·추천기능 승격 금지.**

## 자료와 독립성

- 외부 평가 논문: Huang et al., *Molecules* 2025, 30, 3616, DOI `10.3390/molecules30173616`.
- 논문 Figure 9(원문 PDF p.14)의 **1440분 시점 실험마커를 v30에서 육안 판독한 근삿값**. 데이터 QA 표기가 `NOT_TRAINED`인 무개질 왕겨 6행만 사용. 각 점의 잠정 그래프 판독 허용범위 ±0.5 mg/g. Langmuir `qmax`·kinetic fitted `qe2` **사용하지 않음**.
- 제조: 논문 §3.1(pp.18)에서 N₂ 유량 200 mL/min, 10°C/min, 300/400/500°C, 유지 2시간. **모델 B는 N₂ 유량을 입력받지 않으므로 저장하지 않고 외부 메타로만 인용**. 무개질을 명시적으로 `activation_or_modification='none'`으로 표현, `none_reported`(미보고)로 대체하지 않음.
- 흡착: 논문 §3.4(p.19), Cd(II)·Pb(II), C0=50 mg/L, dose=0.25g/100mL=2.5g/L, pH=5.0±0.2, 25°C, 1440분. 물질수지 상한 20 mg/g. 각 오염물질 내 제조온도만 변경.
- 학습: **기존 Stage 2 Core 98행 / 26 DOI**. 외부 DOI는 학습 자료에 **0행**. v24 이후 보고된 흡착값, v30 그래프값은 학습하지 않음. Stage 1에서 수집된 동일 논문의 BET·TPV는 시료 ID 연결 확인에만 사용하고 **Stage 2 입력변수·모델 학습에 사용하지 않음**.
- 적용범위 경고: Stage 2 학습에는 `rice husk` 13행이 있으나 전부 **두 단계 열처리**이며, **왕겨의 무개질 단일 열분해 조합은 0행**. `activation_or_modification='none'` 범주 또한 학습된 적 없음. 따라서 이는 **동일 원료라도 새로운 공정 조합에 대한 OOD 스트레스 테스트**.

## 모형 사전 지정 및 예측값

주 비교는 기정의 연구용 모델 구성: A(XGBoost), B(Ridge). B(XGBoost)는 추가 감도분석에만 사용. **이 모델들은 해당 원본 집합으로 별도 재학습한 연구용 평가모델이지, 현재 `active.json`의 저장된 배포 모델(`stage2_B_XGBoost`, Core97 학습)을 로드해 예측한 것이 아니다.** 원본 저장 모델은 이 분석환경의 scikit-learn 직렬화 버전 차이(`_RemainderColsList`)로 로드하지 못해 실제 배포 모델의 예측값은 미확인이다. 모델·전처리 재학습은 **98개 기존 관측만** 사용하고, 외부 6개 관측은 추론·평가에서만 사용. 하이퍼파라미터 수정 및 v30 결과를 이용한 선택 없음. 출력값은 clipping **전 원시 예측**.

| 오염물질 | 온도 °C | 그래프 실험값* | Model A XGB | Model B Ridge | Model B XGB (감도) |
|---|---:|---:|---:|---:|---:|
| Cd(II) | 300 | 2.7 | 9.54 | −6.34 | 11.24 |
| Cd(II) | **400** | **7.2** | 9.54 | −5.69 | 12.10 |

\*그래프 확대 육안 판독 근삿값(mg/g); 평형 `qe` 인증이 아니라 **qt(1440min) reported uptake**로만 취급. 일부 모델 수치는 실행 환경의 sklearn/xgboost 버전에 따라 미세한 차이가 있을 수 있음.

### 계열별 점수 (표본 6행, **독립 DOI는 1편**)

| 지표 | A/XGB | B/Ridge | B/XGB (감도) |
|---|---:|---:|---:|
| 6행 MAE, mg/g | 11.40 | 8.20 | 12.49 |
| Pairwise 일치율 (계열별 평균, 동률 0.5점) | 50.0% | 66.7% | 66.7% |
| Top-1 적중 (Cd/Pb) | 동률/동률 | **실패/실패** | **실패/실패** |
| Top-1 적중 기대값 (계열 평균) | 1/3 | 0 | 0 |
| 평균 regret, mg/g | 2.88 | 2.25 | 2.25 |
| 원시 물리 제약 위반 | **3/6** | **3/6** | **3/6** |

- 물리 제약: `0 ≤ qt ≤ C0/dose = 20 mg/g`.
- Model A는 제조조건을 받지 않으므로 온도 세 가지 모두 예측 동률. **동률을 틀림(0점)으로 간주하지 않으며** 3쌍 점수 0.5, Top-1 적중 기대값 1/3으로 평가.
- Model B Ridge는 Cd(II)에서 **음수 3개**를, Model A와 B XGBoost는 Pb(II)에서 **상한 초과 3개**를 출력. 제한값으로 자르면 일견 점수가 개선될 수 있지만, **clipping 결과는 성능·순위 지표에 사용하지 않음**.
- **Core97 재학습 감도분석:** Phase8의 1개 추가 행의 영향을 분리하기 위해 Core97만으로 별도 고정 Ridge/XGBoost를 재학습해 같은 외부 6행을 평가했다. 두 구성 모두 **Top-1 적중 0/2계열, Pairwise 평균 66.7%, 원시 제약 위반 3/6**으로 결과가 동일했다. MAE는 Ridge 6.59 mg/g, XGBoost 15.46 mg/g. 재학습 모델의 수치는 실제 저장된 `active` 모델의 추론값과 같다고 보증하지 않는다.
- Model B는 각 계열에서 300 < 400 < 500°C의 **단조 증가**를 예측하지만 실험 마커는 400°C에서 최대. 3쌍 중 (300,400), (300,500)은 맞고 (400,500)은 틀리므로 pairwise 2/3. 실험 최고 온도와 2위의 차이는 Cd=3.0, Pb=1.5 mg/g으로 ±0.5 근삿값 허용범위가 서로 겹치지 않음. 이는 **육안 판독 오차에 대한 제한된 순위 안정성**이지 실험 반복 오차에 대한 신뢰구간이 아님.
- **양수 MAE가 더 작다고 절대값 정확도·최적화 가능성이 입증된 것은 아님**. 두 계열은 같은 DOI이며 독립 검증 표본으로 간주할 수 없음. 학습 범위 밖에서 높은 원시 위반율을 보이므로 모델 B의 단일 제조온도 추천은 활성화하지 않음.

## QA 및 연구 결론

1. 본 자료는 **학습 승인 0행**을 유지. 원문 Figure 9에 대한 제2 판독자 확인, 의심 지점 정량화가 이루어지기 전에는 모델 학습으로 승격하지 않음.
2. 외부 DOI 홀드아웃은 만족하나 원료–공정 조합이 OOD이며, 단일 DOI의 2개 타깃 계열만으로 일반화 성능을 추정할 수 없음.
3. 실제 온도 추천 성능을 개선하려면 **무개질 또는 개질 방식이 동일하면서 3개 이상의 제조온도를 비교하고, C0/dose/pH/접촉시간이 동일한 독립 DOI**가 추가 필요.
4. v26–v30 기존 원본·배포모델·Streamlit UI·active.json 변경 없음. v31은 평가 코드 및 보고서만 추가.
