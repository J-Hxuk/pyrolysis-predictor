# v41 연구 결과 — 활성 모델 입력범위·제조조건 추천 게이트

작성 기준: 2026-10-30. 기존 배포 A/B와 Stage 1 활성 모델은 **수정·교체하지 않음**.

## 1. 이번 변경 사항

- `pyrolysis/biochar_stage2/v41_scope.py`: 순수 Python 적용범위 검사기. 필수 물리 입력, 모델별 사용 입력, 미보고율, 전역 단변량 학습범위, 미학습 범주, 동일 오염물질(모델 A)·동일 원료+오염물질(모델 B) 관측 행/DOI를 확인.
- `pyrolysis/biochar_ui/stage2_pages.py`: 흡착성능 실시간 그래프/슬라이더 유지하면서 모델 A/B 학습범위 안내 및 입력 항목별 보고율 연결. 검증 화면에 Core 97과 v40 연구용 확장 자료 분리 표시.
- `제조조건 탐색`: 기존 Core 97에서 독립 DOI 2편 이상 **및 같은 DOI·동일 흡착조건의 온도 대비 비교군**이 확인되지 않으면 검증된 순위·최고 제조조건을 표시하지 않음. 대신 사용자가 명시적으로 선택하면 출처 후보의 **미검증 원시 예측 점수표만** 원본 후보 순서대로 표시(순위 열 제거, 물리 위반 항목 보존). 기존 v26의 조건 범위 게이트는 그대로 유지.
- `scripts/audit_v41_paired_stage1.py`: v40 연구용 저장 OOF 예측을 동일 DOI+시료 키로 1:1 매칭하고 DOI-cluster bootstrap으로 Ridge 대비 Poisson MAE 차이 산출. 새 학습 없음.

## 2. 적용범위 검사의 과학적 의미

현재 활성 Stage 2 A/B 학습 원자료는 **Core 97행/25 DOI**이며, v40 확장 연구 데이터 128행/30 DOI와 다르다. 128행에서 관찰된 입력범위가 자동으로 과거 모델에 학습되었다고 표시하지 않는다.

실제 Core 97에서 원료-오염물질 쌍이 2개 이상 DOI에 나타나는 경우: **0쌍**. 따라서 **현행 모델로 검증된 제조조건 순위를 제공할 수 없다.** 이번 게이트는 바로 이를 화면에 보이게 한다. 온도 민감도 모델 응답과 연구용 후보 점수표는 유지하되, 단일 DOI의 모델 점수 크기로 최고조건을 주장하지 않는다.

범위 검사는 각 입력의 주변(min/max)만 검사하며 여러 변수의 **공동분포를 증명하지 않는다**. 데이터가 희소한 영역의 입력/원료/흡착조건에는 경고가 표시된다. 불확실성 신뢰구간은 계산하지 않으며 예측 확률이나 교정 신뢰도를 만들어 내지 않는다.

신뢰구간 모두 0 포함. 새 배포로 교체할 객관적 근거 부족. 또한 기존 OOF 파일에 `fold_id` 열이 없어 동일한 *예측 대상 시료와 DOI*는 엄밀히 확인했지만, 두 모델이 정확히 같은 fold 할당을 사용했는지는 원본 평가 코드의 분할 정의에 의존한다. 이미 반복적으로 모델 선택에 사용한 DOI이므로 독립 신규 외부 검증이 아님.

## 5. 공동 작업자에게 필요한 데이터 (우선순위)

1. **동일한 원료·동일 중금속** 조합에서 제조온도를 최소 3수준 비교한 서로 다른 DOI의 논문. pH, C0, 투입량, 흡착 시간/온도를 같은 비교군 내부에 고정해야 함. 실제 실험 qe 또는 원래 제거율·질량수지 조건 필수. qmax/qt는 qe와 분리.
2. 제조 전 원료 C/H/O/N/S 및 VM/Ash/FC(기준 명기), 제조온도·유지시간·승온·분위기, 같은 *물리적 제조시료*의 BET·**총기공부피**가 같이 있는 데이터. 바이오차 제조 후 조성을 원료 특성으로 바꾸지 말 것.
3. 최종 블라인드 외부 검증용으로 모델 설계·튜닝에서 완전히 제외할 DOI **3편 이상**을 미리 선정. 예측온도 비교를 위해서는 해당 DOI에서 실제 제조온도별 실측 흡착량 필수.

## 6. 파일 관리

패치는 기존 v40 기준 전체 프로젝트를 다시 포함하지 않고 **바뀐 코드 2개·새 테스트·분석 스크립트·보고서만** 담는다. 예전 ZIP을 자동으로 이동·삭제하지 않는다. `scripts.audit_project_hygiene_v40`은 진단 전용으로 계속 사용. 3~5개 패치마다 통합 기준본을 마련하고, 설치가 끝난 vXX ZIP만 별도 아카이브 보관 권고. v15/v41/v60 원본·검증 추출본·활성 모델은 무검증 이동 금지.
