# v50 — 흡착량 예측의 실제 실용성 평가

## 1. 무엇을 검토했는가

- 원자료: `data/imports/v46_phase8/Stage2_140_SOURCE_VERIFIED_AUGMENTED_RESEARCH.csv` (140행, 32 DOI). 원본은 읽기 전용으로 사용했다.
- 목표: 문헌에 보고된 **흡착량 qe 계열**의 예측. 논문에서 직접 실측 평형이 독립적으로 인증되지 않은 행과 그래프 근사 행도 포함된 **연구용 혼합 품질 코호트**다. `qt`, Langmuir `qmax`, 복합 침출수 타깃은 새로 혼합하지 않았다.
- 검증: 동일한 5-fold `GroupKFold(doi)`. 학습·테스트 DOI 겹침 없음. 데이터 전처리는 각 fold의 학습 자료에서만 적합했다.
- 모든 MAE는 동일한 holdout 예측에 대한 mg/g 단위. 결과는 이미 여러 번 사용된 DOI의 교차검증이며 **새로운 블라인드 외부 검증이 아니다**.
- 활성 앱 모델은 바꾸지 않았다.

## 2. 전체 140행 결과

| 모델 | MAE (mg/g) | R² | 물질수지 위반 | 상한에 붙은 예측 |
|---|---:|---:|---:|---:|
| 흡착조건 A 원시 XGB | 23.12 | 0.605 | 44 | 0 |
| 흡착조건+제조조건 B 원시 XGB | 24.94 | 0.576 | 50 | 0 |
| A 사후 물질수지 제한 | **17.25** | **0.698** | 0 | **43** |
| B 사후 물질수지 제한 | 17.69 | 0.687 | 0 | 50 |
| A 제거율 직접 학습(logit fraction) | 20.04 | 0.518 | 0 | 0 |
| B 제거율 직접 학습(logit fraction) | 21.10 | 0.505 | 0 | 0 |
| 오염물질별 중앙 제거율 기준선 | 23.10 | 0.286 | 0 | 0 |
| Cd/Cu 전용 A 모델 + 나머지 A | 21.74 | 0.588 | 0 | 24 |
| Cd/Cu 전용 B 모델 + 나머지 B | 19.95 | 0.619 | 0 | 34 |

사후 제한: `qe_hat = clip(qe_raw, 0, C0/dose)`. 관측값 140행 중 **99% 이상 제거율에 해당하는 행은 6개**인데, A 사후 제한에서는 예측 43개가 최대 제거량에 붙었다. 사후 보정의 MAE 감소는 물리 법칙 학습의 증거가 아니다. 물질수지는 단일 용질의 수용액 배치실험을 전제로 해석한다.

## 3. 원료·오염물질별 전용 모델이 무조건 좋은가? — 아니오

Cd 67행/12 DOI, Cu 31행/9 DOI에 각각 독립 모델을 학습해도 전체 모델보다 정량 MAE가 개선되지 않았다. 각 fold에서 train DOI가 5개 미만이거나 train 행이 12개 미만이면 글로벌 모델로 대체하는 고정 규칙을 사용했다.

### 제한적 개선 후보

| 오염물질 | 비교 | 이전 MAE | 후보 MAE | 개선 DOI | DOI 부트스트랩 95% 구간 (후보−기존) |
|---|---|---:|---:|---:|---:|
| Cu(II) 31행/9 DOI | A 사후 제한 → 글로벌 A 제거율 직접 학습 | 13.12 | **9.11** | 6/9 | **−13.21 ~ +0.94 mg/g** |
| Cd(II) 67행/12 DOI | A 사후 제한 → 글로벌 B 사후 제한 | 10.68 | **8.94** | 8/12 | **−4.62 ~ −0.15 mg/g** |

부트스트랩 단위는 **행이 아니라 DOI**, 3000회다. 수치가 구간에 걸쳐 변하고 논문 수가 적으므로 Cu 결과는 확실한 개선이라고 주장할 수 없다. Cd 결과도 반복 사용된 자료에서 나온 *탐색적 사후 하위집단 분석*이며 독립 DOI에서 재현돼야 한다. 따라서 **오염물질별 자동 모델 전환은 아직 채택하지 않는다.**

Cu 후보의 올바른 정의는 ‘전체 140행으로 학습한 A 제거율 모델을 Cu에 평가’한 것이다. **Cu 31행만으로 따로 학습한 모델이 아니다.** 별도 저장 스크립트도 이 방식을 유지한다.

## 4. BET/TPV를 더하면 qe가 좋아지는가? — 관찰되지 않음

실측 BET와 TPV가 모두 확인되는 **동일한 103행·27 DOI**만 대상으로 A/B/C를 같은 DOI 분할에서 평가:

| 모델 | MAE (mg/g) |
|---|---:|
| A + 사후 제한 | **17.32** |
| B + 사후 제한 | 17.40 |
| C (= B + **실측** BET/TPV) + 사후 제한 | 17.97 |

**실측 물성 추가 이점이 확인되지 않았다.** 게다가 C는 물성을 이미 측정한 경우에만 가능하다. Stage 1 **예측 BET/TPV**를 넣는 D 모델이 이 결과로 검증된 것은 아니다. 이를 실제 기능인 것처럼 표시하면 안 된다.

## 5. 제조온도별 순위 추천은 가능한가? — 불충분

같은 DOI·원료·오염물질·흡착농도·pH·투입량·접촉시간·제조경로(정규화 라벨) 조건에서 제조온도 3수준 이상인 비교군은 **11개 패널 / 6 DOI**였다. 그래프 판독 근사 데이터가 일부 포함돼 있다. 서로 같은 DOI의 패널은 독립 표본이 아니다.

| 방법 | 순위 계산 가능한 패널 | 실제 최고온도 일치 |
|---|---:|---:|
| A (제조온도 입력 없음) | **0/11** | 정의 불가 |
| B + 사후 제한 | 7/11 | 3/7 |
| Cd/Cu 전용 B + 사후 제한 | 9/11 | 5/9 |
| B 제거율 직접 학습 | 11/11 | 2/11 |

제조온도에 따라 예측값이 같으면 순위를 억지로 부여하지 않았다. 따라서 A는 `0/11` 실패가 아니라 **모델 정의상 온도 추천을 할 수 없는 모델**이다. B도 일관된 신뢰성이 부족하고, 전용 모델의 5/9는 정량 MAE가 악화된 결과와 함께 해석해야 한다.

## 6. 실제 사용 판단

- **가능:** 문헌 범위와 유사한 조건에서 qe를 탐색적으로 추정하고, 범위와 한계를 표시한다.
- **연구용 유망 후보:** Cu용 글로벌 A 제거율 직접 학습; Cd용 글로벌 B의 흡착량 예측 (독립 DOI 추가 확인 전까지 비활성).
- **불가/미검증:** 최적 열분해온도 자동 추천, BET→qe 인과 추론, 미보고 pH의 정확한 예측, 1개 DOI만 있는 Zn 계열에 대한 일반화 주장.
- **즉시 필요한 데이터:** 동일 오염물질에서 원료·용액조건을 고정하고 온도 3~5수준을 달리한 독립 논문/실험 시리즈, 원문 기준 C0·dose·pH·접촉시간·qe 직접 수치, 가능하면 매칭 BET/TPV. 직접 측정과 피팅값·그래프 판독값 구분 필수.

새 데이터가 수집되기 전에는 UI의 ‘최적 조건 추천’ 문구를 확정적 기능으로 내세우지 않는다.
