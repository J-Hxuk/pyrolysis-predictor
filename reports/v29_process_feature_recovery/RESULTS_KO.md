# v29 — 원문 제조정보 복원 및 열분해온도 검증 준비

2026-10-30. **연구용 분석 패치**. 기존 98행 Core Stage 2, v15/v16 데이터, v27 예측기, Stage 1/v60, 앱 및 active.json 불변. v24 신규 Stage 2 후보는 학습에 사용하지 않음.

## 1. 검증 질문과 데이터

**질문 A:** 이미 수집한 원문 제조·전처리 기록의 시약 이름을 Model B의 입력변수로 안전하게 변환하면, 서로 다른 제조시료가 동일 입력으로 합쳐지는 문제를 줄일 수 있는가?

**질문 B:** 이 변환이 새 DOI에서의 qe 예측과 제조조건 상대 순위를 개선하는가?

Stage 2 **98행 / 26 DOI**, 동일 원시 타깃 `reported uptake`, 같은 외부 LODO 분할, 기존 Ridge 하이퍼파라미터 alpha=10. 기존 B에는 아무 필드도 추가하지 않으며, 별도 연구용 모델에만 시약 서명 `v29_reagent_signature` 한 개를 추가. 원문에 없는 시약량은 복원하지 않았음. 원료명·시료명·DOI·ID·답변/타깃으로 시약 서명 생성 금지. `P-only`처럼 이름만 기재되고 정확한 제조법이 불명확한 경우 **LABEL_ONLY_METHOD_NR**을 명시.

기존 마스터 441행에 없는 Phase 8 신규 almond 시료는 제조정보를 만들어내지 않고 `REAGENT_NOT_REPORTED`로 둠.

### 제조정보 식별 가능성 (v28 동일 30쌍)

| 지표 | 기존 계약 | 원문 시약정보 추가 |
|---|---:|---:|
| 타깃값이 서로 다른 시료 쌍 | 30 | 30 |
| 서로 다른 시료지만 입력이 동일한 쌍 | **6** | **0** |

기존 중복 쌍이 확인된 계열은 cow litter / sewage sludge / rice straw. 이는 **데이터 계약의 식별 가능성** 개선이며, 입력변수의 과학적 설명력 또는 새로운 원료에 대한 일반화가 증명된 것은 아님. 소표본에서 원문시약의 이름만 추가하면 기존 0이던 식별 불가 쌍은 사라질 수 있음.

### 예측 성능 — DOI 홀드아웃, 원시 출력

| 지표 | v27과 동일 기존 B Ridge | 추가 시약입력 연구용 B |
|---|---:|---:|
| LODO MAE | 29.0466 mg/g | **30.8830 mg/g** |
| LODO R² | 0.39286 | 0.39271 |
| 전체 98행 물질수지 제약 위반 | 47/98 | 48/98 |
| 제조조건 비교군 평균 Pairwise | 0.8712 | 0.8561 |
| 제조조건 비교군 예측 동률 | 10쌍 | 8쌍 |

**모델 개선 실패.** 구분이 가능해진 쌍과 실제로 예측 정확도가 향상된 쌍은 동일하지 않다. 새 변수는 표본 수에 비해 범주 수가 많고 DOI 종속성이 강할 수 있으므로 기존 모델을 교체하지 않는다.

원시 예측은 clipping하지 않았음. 11개 실측 비동률 비교군 기준 물질수지 위반 수는 기존 16행, 새 모델 18행이며, 기존 v27 전체 12개 비교군 33행의 위반 수 17행과 분모가 다름. 기존 B 재계산 결과는 v27에 저장된 33개 OOF 원시 예측과 수치가 완전히 일치함.

**사후설계 주의:** v28의 실패 사례를 확인한 다음 시약 서명을 정했으므로 이 결과는 탐색적이다. 7 DOI에 포함된 비교군은 상호 독립이 아니며, 통계적 개선 주장 금지.

## 2. 진짜 열분해온도 추천의 검증 준비

v28 Core qe의 동일 흡착조건 비교군에서는 열분해온도 변화가 확인된 그룹이 **0**이었다.

v24에 이미 별도 저장된 **Langmuir qmax fitted 자료 32행, 5 DOI**를 Phase 8 Stage 1 시료명·DOI에 일대일 조인하였다. **3 DOI의 8개 온도 비교계열(총 26개 qmax 기록)**을 식별했다. 대상 DOI:
- `10.3390/molecules30173616`: Rice husk, Cd/Pb, 무개질·HNO3·KOH의 각 300/400/500°C 계열
- `10.3390/toxics12010008`: Urban green waste, Cd, 350/450/550/650°C
- `10.1039/d5va00202h`: Sewage sludge, Pb, 400/500/600/700°C

**별도 단일 DOI 사례:** v24의 poultry manure 논문(`10.3390/ma14216566`)은 실제 Table 7에 보고된 uptake 51행에서 오염물질·C0·pH·투입량·접촉시간이 같은 **17개 온도 비교계열(425/575/725°C)**을 구성할 수 있다. 다만 동일 DOI 1편에 불과하고, 투입량이 100 g/L로 기존 Core 범위 밖이며 침전 위험이 있다. 각 계열의 최대 흡착량 차이는 0.0207 mg/g에 불과해 물질수지 상한 근처의 매우 작은 차이로 해석해야 한다. **새로운 DOI의 온도 추천 정확도 검증으로 사용할 수 없다.**

**이는 qmax 피팅계열일 뿐 실측 qe의 열분해온도 추천 검증은 아니다.** 데이터만으로 새로운 온도 추천 모델 성능은 평가 불가능하다. 다음 수집에서 같은 시료의 실측 qe 또는 Ce, 동일 C0/dose/pH/시간/온도, 제조 경로를 확인해야 한다. 원문 그래프에서 값을 추출하면 그래프 유래 값으로 별도 보관하고 정확도와 출처를 기록해야 한다. qmax와 qe를 합치면 안 된다.

## 3. 제공 파일 및 안전성

- `scripts/evaluate_v29_process_feature_recovery.py`: 출처 기반 시약 서명 추출 + 동일 LODO 비교
- `scripts/audit_v29_temperature_readiness.py`: qmax 데이터 시료 연결 및 온도 비교계열 탐색 **(학습 없음)**
- `tests/test_v29_process_feature_recovery.py`: 9개 회귀/계약 검사
- `reports/v29_process_feature_recovery/*.csv/*.json`: 원문 증거 및 예측, 가금분 단일 DOI 온도 비교자료의 연구용 기록

관련 v27/v28 포함 **26 테스트 통과**. 전체 pytest와 Windows Streamlit 실렌더링은 미검증. 입력변수 계약, 배포모델, UI 변경 없음. Source note에서 화학식 패턴을 파싱하는 방식이기 때문에 정규표현식은 정확한 시약/공정을 모두 복원하지 않으며, 자료의 provenance 상세감사는 별도로 필요.

### 다음 안전한 순서

1. 새 모델 채택하지 않음; v29 시약 입력 필드는 학습용 후보로 보관.
2. Phase 8 및 v24 원문 3 DOI에서 **실측 qe 또는 Ce**의 동일 흡착조건 온도계열 확보 여부 검토.
3. 확보 후 실측 qe만 대상으로 DOI 전체 홀드아웃 순위 검증. 반드시 무작위/물리 baseline, 동률, 물질수지 원시 위반율을 함께 보고.
4. 별도 데이터에서 개선 검증되면 그때 제조조건 추천 UI에 승격.
