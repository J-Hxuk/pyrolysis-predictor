## 1. 새 자료와 원문 계보

- 사용자 전달 `Biochar_Kiro_Handoff_CurrentBatch.zip` 원본: 36행 (Shen 2017 29, Cao 2019 7), 원문 7 PDF(main/SI) + 보류 SI 1 PDF, QC workbook, README.
- Shen (DOI 10.1007/s11356-017-8847-2) 29행: Ni(II) Figure 6의 **실험 평형 흡착량 그래프 점을 vector-extracted**. 표 피팅 Langmuir Qmax 아님. 원문 p8 Fig6은 equilibrium isotherm, pH5, 20°C, 24h, biochar 0.1 g/용액 20mL 조건을 명시. C0 29.3467 등은 사용자 전달 표의 변환 수치를 보존하였으며 독립 Ce 실험값으로 간주하지 않음. BET 4값은 원문 Table1; TPV는 NR.
- Cao (DOI 10.1016/j.scitotenv.2019.07.102) 7행: 300–900°C에서 Table 2의 Pb(II) 실험 **qTotal** (51.07, 94.96, 109.45, 124.58, 141.82, 157.95, 152.83 mg/g). 원문 p3 Methods의 100 mg/L, dose 0.6g/L, pH5, 25°C, 48h에 대응. `qTotal`은 원시료 실험 흡착량으로 계산돼 Langmuir Qmax가 아니나, 48h 별도 plateau 증빙은 확인되지 않음. Stage2 research uptake 범주로 유지.
- 36행 모두 비음수 및 qe≤C0/dose 점검 통과. **원문/전달 CSV 변경 없이** 분리 보관하고 별도로 feature 스키마로 매핑. 같은 DOI/Material을 fold 양쪽에 투입하지 않음.
- Stage1 BET는 네 고유 제조시료만 추가(446→450), 같은 시료의 여러 C0를 BET 중복 측정으로 간주하지 않음. 원료 C/H/O와 열분해 후 biochar C/H/O를 혼합하지 않음.
- Alam/Sun/Zhao 및 Uchimiya SI는 원문을 유지하며 수치 불확실성을 무시해 허위 숫자를 추출하지 않음. 학습 스키마 불일치를 이유로 원문 전체를 삭제하지 않음.

## 2. Stage2 기존 DOI에 대한 고정 평가

- **공통 시험:** 기존 140개 관측·32 DOI, GroupKFold 5분할, fold 내부 Pipeline fit.
- 비교 대상은 기존 140행만으로 얻은 OOF 예측. 신규 DOI는 이 공통 평가에서 학습 전용 증량으로 참여하고 평가 DOI는 포함하지 않음.
- 각 예상값을 `0 ≤ qe ≤ C0/dose`로 clipping하였으며 clipping 전 상한 위반 수는 원본 metrics CSV에 별도 기록.
- Source-addition 및 모델 선택에 이미 이 평가결과를 사용했으므로 **사후 탐색적 비교**로만 해석.

| 학습 시나리오 | Model A MAE (mg/g) | Model B MAE (mg/g) |
|---|---:|---:|
| old140 | 17.247 | 17.690 |
| v55_152 | 16.588 | 17.530 |
| v55_156_conditional | 16.666 | 17.386 |
| v57_159_cao_only | 16.683 | 17.385 |
| v57_181_shen_only | 18.710 | 19.677 |

기존 v55 152행 대비 새 36행 전체를 동일 가중치로 추가하면 Model A는 **16.588 → 18.792**, B는 **17.530 → 19.934**로 악화. Cao 7행만 추가하면 B MAE **17.530 → 17.385**로 소폭 개선되지만, DOI paired bootstrap 95% 구간이 0을 포함하여 통계적 개선 입증 불가. Shen 29행만 추가하면 두 모델 모두 악화.

## 3. 신규 DOI 전체 제외 예측 (사후 source-out)

이 절차는 **신규 DOI 관측 36행이 학습에 들어가기 전의 v55 모델을 재학습한 다음** 이들을 예측하므로 DOI 간 분할은 엄격. 그러나 사용자가 원문 자료를 제공하고 모델 개발자가 이를 이미 확인했기 때문에 **미래 사전 봉인 독립검증은 아님**.

| 신규 DOI | 사전 학습 시나리오 | Model | 시험 행 | MAE (mg/g) | 0 예측 MAE (mg/g) |
|---|---|---|---:|---:|---:|
| shen | v55_152 | A | 29 | 10.063 | 8.403 |
| shen | v55_152 | B | 29 | 10.186 | 8.403 |
| cao | v55_152 | A | 7 | 61.382 | 118.951 |
| cao | v55_152 | B | 7 | 80.659 | 118.951 |
| shen | v55_156_conditional | A | 29 | 13.019 | 8.403 |
| shen | v55_156_conditional | B | 29 | 10.217 | 8.403 |
| cao | v55_156_conditional | A | 7 | 59.326 | 118.951 |
| cao | v55_156_conditional | B | 7 | 77.707 | 118.951 |

Shen은 기존 v55 Model A/B 모두 0 예측 기준선(8.403)보다 오차가 크다. 반면 Cao는 두 모델 모두 0 기준선(118.951)보다 낮으나 절대오차가 큼. 기존 Model B는 Cao 온도별 조건 순위에서 동률이 발생해 **top-1 regret을 정의하지 않음**. 이를 임의로 1순위 확정하지 않음.

## 6. 데이터/배포 정책

- **새로운 정본 데이터셋:** Stage2 159/181/188/192/204/208 (연구용), Stage1 450 (연구용). v55의 152/156/168/172 및 v46 140은 변경하지 않음.
- **새로운 예측기:** Stage2 A/B × 6가지 증량 시나리오 12개, DOI 가중치 A/B × 2개 가중치 4개, Stage1 BET 1개 = 17 Joblib. **활성 모델 불변.**
- 예측 정확도 기준 개선 모델과 제조온도 추천 정확도는 별도로 판단. 강제 clipping 후 지표와 clipping 전 물질수지 위반 건수 함께 보고.
- 다음 추가 원문은 신규 논문이든 기존 논문의 보충 수치든 `source_value_type`/DOI/시료/결측값을 유지한 뒤, 동일 기존 DOI 시험 + 신규 DOI source-out으로 재학습/검증.
- **모델 환경** Python {platform.python_version()} / scikit-learn {sklearn.__version__} / XGBoost {xgboost.__version__}. 사용자 PC 1.5.2 환경에선 Joblib version warning이 가능하므로 로컬에서 연구용 재학습 후 재현성 검증.

## 결론

**새 원문은 전부 보존, 학습은 실제 진행, 그러나 36행 일괄 증량의 전이 성능 향상은 확인되지 않았다.** Source별 학습 비중 조절 및 적용 영역 구분이 다음 연구 과제. 최신 데이터가 많다는 이유만으로 이전 모델을 폐기하지 않는다.
