# Biochar v45 연구용 신규 DOI 통합·재학습 결과

> 2026-10-30. 본 문서는 학부 학술대회용 개발 기록이다. **기존 앱의 활성 모델을 변경하지 않는다.**

## 요약

- 신규 DOI **4편**, 본문 PDF 4개 + 보충 PDF 3개(총 7개), 기존 통합 DOIs와 중복 **0편**.
- Stage1 제조시료: **381 → 404행**. 신규 23행 중 **정확한 수치로 검증된 BET 12행, TPV 5행**; 누적 BET **348**, TPV **218**.
- Stage2 reported uptake 연구 후보: **128 → 138행 / 독립 DOI 30 → 32편**. 새 흡착량 10행(하수슬러지 2014/2018 각 5행)은 그래프에서 수동 판독한 **근사치**이며, 적어도 한 명의 독립 재판독 전에는 정식 학습 승인하지 않음.
- `10.1016/j.jhazmat.2021.125785`의 Cd 18.2/23.6/46.5/49.0 mg/g은 **pseudo-second-order fitting 평형 qe**이며 실제 관측 시점 실측값과 동일하지 않으므로 **별도 보존**.
- `10.3390/w17070918`의 시료 9개는 Stage1 후보 레지스트리에 포함하되 BET는 Fig.1B뿐이라 수치결측 유지; Pb/Cd Fig.4·5는 온도 시리즈가 있지만 재현 가능한 수치 추출 전 **학습 보류**.
- Sakhiya 가정 데이터 6행은 `Volume_reported=5mL`, `Volume_assumed_corrected=50mL`, `inferred_typo_not_author_verified`, **메인 학습 제외**로 기록.

## 비교 실험 결과

기존 **DOI 128행 (Stage2)** / BET **336행**, TPV **213행**을 **동일 검증행**으로 고정했다. 각 old-DOI GroupKFold 학습 fold에 신규 DOI만 추가한 *cold refit*와, 기존 old 모델 상태에서 **새 DOI 10행에 40개의 XGBoost tree를 이어 학습한 warm continuation**을 별도로 시험했다. 전처리는 항상 old-fold 안에서만 학습. 실제 배포 모델이 아닌 연구용 모델 구성이다.

| 대상(고정 구 DOI) | 기존 데이터 재학습 MAE | 전체 병합 후 처음부터 MAE | 진짜 이어학습 MAE |
|---|---:|---:|---:|
| Stage1 BET / Poisson (m²/g) | 239.44 | **250.04** | 미지원 |
| Stage1 TPV / Poisson (cm³/g) | 0.18073 | **0.18842** | 미지원 |
| Stage2 A / XGBoost (mg/g) | 18.66 | **21.34** | 23.01 |
| Stage2 B / XGBoost (mg/g) | 21.26 | **24.11** | 29.72 |

즉 이번 신규 자료를 학습에 넣었을 때 **같은 구 DOI에서의 오차가 증가**했다. 특히 10개에 불과한 그래프 판독 자료로 기존 XGBoost를 **이어학습하는 방식은 더 불안정**했다. 따라서 **새 모델은 활성화하지 않는다.** 이것은 신규 논문의 실험이 틀렸거나 버려야 한다는 의미가 아니다. Figure 근사치의 판독 오차와 신규 제조경로의 분포차이가 모두 영향을 줄 수 있다.

다음 결과는 **평가 대상까지 신규 DOI를 포함한 별개의 5-fold 교차검증**이라 위 표와 직접 나란히 성능 개선을 계산할 수 없다.

| 모델 | 전체 DOI 그룹5 MAE | R² | 음수 예측 |
|---|---:|---:|---:|
| BET Poisson | 237.39 m²/g | 0.489 | 0 |
| TPV Poisson | 0.18156 cm³/g | 0.319 | 0 |
| Stage2 A XGBoost | 21.91 mg/g | 0.630 | 1 |
| Stage2 B XGBoost | 23.90 mg/g | 0.579 | 5 |

Stage2 A 기존 구 DOI 고정 평가의 물질수지 위반은 **29/128**이었고, 신규 병합 cold refit은 **47/128**이었다. B는 **44/128 → 48/128**. `np.clip` 개선은 무효한 예측을 구간에 끼워 넣는 효과라 학습능력 개선으로 간주하지 않는다.

## 과학적·실무적 한계

1. 신규 qe 10개는 **표에 수치로 출판된 정확한 데이터가 아니다**. 2014의 47.44 mg/L 지점과 2018의 막대그래프를 **수동 판독한 근사치**이며 `graph_readout_uncertainty_mg_g`를 반드시 유지한다.
2. 출처별 실험 초기 pH/제조 유지시간 등 결측은 **임의로 채우지 않는다**. 결측 대체는 훈련 fold 안에서 학습된다.
3. 신규 데이터 DOI가 2편뿐인 Stage2 개선을 인과적으로 해석하면 안 된다.
4. 새 논문 원문 PDF는 과거의 별도 사용자 업로드 ZIP 안에 보존되어 있고 **v45 배포 패치에는 용량 절약을 위해 중복 포함하지 않는다**. SHA-256 목록은 `data/imports/v45_independent_do_is/source_sha256_manifest.json` 참고.
5. 이 비교에는 이미 개발 과정에서 사용한 기존 DOI가 포함돼 **최종 블라인드 외부 검증이 아니다**. 학부 학술대회 발표에서는 `탐색적 DOI 그룹 검증`이라고 표현한다.

## 실무 의사결정

- 현행 v44 UI 및 활성 모델은 유지한다.
- 전처리/타깃이 완전히 호환되는 새 데이터를 보존하고, 추가 논문이 확보되면 **from-scratch 재학습**으로 평가한다. **이어학습**은 신규 데이터가 소량·분포가 다른 상황에서 우선권을 주지 않는다.
- Figure-only Water(2025)는 독립 재판독이 가능하다면 `제조온도 3수준×원료 3종×금속 2종`의 비교 자료로 추가할 수 있다. 단, 전 범위 digitization보다 대표 농도 1~2점을 고정해서 판독해도 충분하다.
- 다음 버전은 추가 알고리즘 실험보다 프로그램의 **시연 흐름과 모델 버전·입력 제한을 사용자에게 보여주는 기능**에 집중한다.
