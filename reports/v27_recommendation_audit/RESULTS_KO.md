# Stage 1–2 v27: 독립 DOI 제조조건 순위와 로그 모델 안정성 감사

2026-10-30 · 연구용 재평가. **모델 재학습·배포모델 교체 없음. v24 신규 69행은 학습에 미투입.**

## A. 질문과 방법

**질문:** 같은 원료·오염물질·흡착조건에서 제조조건만 다른 실험들에 대해, 해당 논문 전체를 제외하고 학습한 Model B가 qe 순위를 맞힐 수 있는가?

- 기존 Stage 2 Phase 8 Core **98행·26 DOI**에서 DOI + 원료 그룹 + 오염물질 + C0 + dose + 초기 pH + 흡착온도 + 접촉시간이 **모두 동일한 비교군**을 추출. 이 비교군 내 제조 입력변수 값이 다른 시료가 최소 2개 있어야 함.
- 총 **12개 제조조건 비교군 / 33행 / 8 DOI**가 확인됨. 이 가운데 1개 비교군은 실측 흡착량이 모두 같아서 순위 평가가 불가능함. 따라서 유효 실측 순위 **11개 비교군 / 7 DOI / 평가가능한 30쌍**.
- 각 DOI를 전체 홀드아웃하고 다른 DOI의 행에만 기존 Model B Ridge 알고리즘을 fit하여 원시 qe를 예측. Model B의 기존 입력 변수 계약 그대로 사용하며, 금지 필드·원문 검증값·실측 qe는 X에 쓰지 않음.
- **Pairwise rank accuracy**는 실측 동률 쌍을 제외하고, 예측 동률은 임의로 승자를 정하지 않고 **0.5점(무작위 동률 해소 기대점수)** 부여. 비교군별 동일가중치(macro), 전체 쌍별 가중치(pooled), DOI별 동일가중치(DOI macro)를 구별함. 약한 실측 차이 1/2 mg/g 미만인 쌍을 제거하는 민감도도 추가함.
- **Top-1**은 한 번에 사용 가능한 동일 조건의 후보들 내 관측 최고를 맞혔는지로 정의. 예측 1위 동률이면 균등 무작위 선택의 기대 적중률로 계산. 16조건 전역 최고 또는 신규 바이오매스 최적화 검증이 아님.
- 모든 원시 예측에서 `0 ≤ qe ≤ C0/dose` 확인. 이 제약에 맞추기 위한 **clipping은 수행하지 않음**. 하나라도 위반한 비교군에서는 사용자용 정량 추천 근거가 성립하지 않는다고 판단함.
- 데이터/알고리즘의 선택은 이전 v15/v16/v25 연구에서 이루어졌으므로 이번 분석은 **탐색적 사후 검증**이며, 독립적인 새 코호트에서 수행한 전향적 외부 검증 또는 완전한 nested algorithm selection은 아님.

## B. Stage 2 주요 결과

| 평가 정의 | 결과 |
|---|---:|
| 제조조건이 2개 이상인 비교군 | 12개 / 8 DOI |
| 실측 결과 차이가 존재하여 순위 평가 가능한 비교군 | **11개 / 7 DOI** |
| 유효 비교쌍 수 | **30쌍** |
| Model B, 비교군별 평균 Pairwise (동률 0.5점) | **0.8712** |
| Model B, 전체 비교쌍 가중 평균 | **0.8333** |
| DOI별 동일가중 Pairwise | **0.8929** |
| 비교군 내 Top-1 기대 적중 | **0.6212** |
| 균등 무작위 후보 선택 Top-1 기대 적중 | **0.3712** |
| 비교군 내 실제 최고 대비 기대 regret | **8.95 mg/g** |
| 균등 무작위 후보 선택 regret | **21.66 mg/g** |
| 물질수지 범위 위반 원시 qe 예측 | **17/33행** |
| 원시 예측이 모두 물리적으로 유효하며 실측 순위 차이 있는 비교군 | **6개 / 5 DOI** |
| 예측 동률이 존재하는 비교군 | **8개 / 12개** |

- 7개 DOI의 동일가중 Pairwise 평균은 0.8929였고, DOI를 군집 단위로 resample한 기술적 95% 구간은 약 [0.8214, 0.9643]. **n=7로 작고 사후 선택된 검증이며, 이 CI로 추천 모델의 독립 일반화 능력을 확증할 수 없음.**
- 특히 4개 citrus-peel 비교군(같은 DOI)의 원시 예측은 **12개 모두 물리 제약 위반**. 다른 1개 sewage-sludge DOI도 4개 모두 위반. 성능이 높아 보이는 순위와 실제 배포 가능성이 다름을 보여줌.
- 6개 물리적 완전 유효 비교군의 평균 Pairwise는 0.9167이지만, **예측 결과에 따라 선별된 부분집합**이며 5 DOI뿐이므로 전체 모델 성능의 편향 없는 추정치로 주장 불가.
- 12개 비교군 중 1개는 실측값이 동률이어서 순위 성공 여부를 판정할 수 없음. 이 비교군은 Top-1/Pairwise 전체 요약에서 제외.
- 제조조건 차이가 데이터에 제대로 인코딩됐는지 추가적인 원문별 공정 계약 감사가 필요. 모델이 여러 후보에 같은 값을 예측하는 경우가 많아, 데이터에 있는 실험상 차이를 개별적으로 분해했다고 보기 어려움.

**해석:** Model B는 동일 DOI 내 제조조건 순위에 관한 일부 신호를 포착한 것으로 보이나, **물리 위반(17/33)과 작은 DOI 수 때문에 최적 제조조건의 정량 추천 모델로 배포할 수 없음.** Chen16의 동일 논문 내 12/4 holdout보다 질문에 적합한 검증이지만, 독립적인 전향적 검증을 대신하지 못함.

## C. Stage 1 로그 변환 강건성

이번에는 v26에서 계산한 고정 모델의 OOF 예측만 재분석하여 **원본 RF vs log-target RF**의 DOI별 오차와 크기별 오류를 감사함(재학습 없음).

| 대상 | 개선 DOI | 악화 DOI | 비고 |
|---|---:|---:|---|
| BET, 262행·32 DOI | **19** | 13 | 평균 MAE 감소하나 DOI에 따라 큰 악화 있음 |
| TPV, 199행·29 DOI | **14** | 15 | DOI별 개선 일관성 없음 |

BET 실측 ≤30 m²/g 구간(46행): MAE **106.15 → 84.32 m²/g**. 이는 오차 감소지만 실측 물성보다 오차가 큰 구간이므로 실용적 정밀예측으로 취급하지 않음. v26 외부 33행에서 보인 BET MAE 감소 역시 이미 여러 차례 확인한 도전셋 결과라 확증 자료가 아님. 외부 R²는 여전히 음수였음.

## F. 다음 결론

1. **Stage 2 제조조건 추천은 계속 실험 후보 shortlist 수준으로 한정.** 원료·제조경로별 일반화 주장 금지.
2. 추천 후보의 물리 위반을 선제 차단하고, 모델이 예측 동률이면 임의의 우열을 만들지 않아야 함.
3. 독립적인 추가 DOI에서 **같은 흡착조건으로 3종 이상 제조시료**의 실측 qe와 BET/TPV를 연결 확보하는 것이 다음 검증의 가장 높은 가치.
4. Stage 1 로그 모델은 BET 개선 경향을 별도 연구용 옵션으로 유지. TPV 및 신규 원료 일반화 확정 금지.
