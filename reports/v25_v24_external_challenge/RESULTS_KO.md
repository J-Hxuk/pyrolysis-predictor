# Biochar Stage 1–2 v25: v24 신규 DOI 외부 스트레스 테스트

**분석일:** 2026-10-30  
**범위:** v24 스테이징 자료의 연구용 외부 평가. **학습 승인, 모델 개선, 배포 모델 교체 아님**.  
**재현 명령:** `python -m scripts.evaluate_v24_v25`

## 평가 설계

- Stage 1: v23의 **고정 RandomForest 비교 모델**(v60 배포 모델과 다름)을 Phase 8 기존 264행 중 승인된 BET/TPV 대상에서 학습하고, DOI가 겹치지 않는 신규 6편의 33시료를 직접 예측했다. **신규 33행은 학습에 사용하지 않았다.**
- Stage 1의 v24 연구용 297행 테이블은 신규 33행의 `process_stage`, `v59_route_family`, `activation_method`가 결측이다. v25에서는 신규 원문 추출표의 `manufacturing_route`를 근거로 위 항목을 **연구용 평가 시에만** 명시적으로 사상했다. 원본 v24 테이블은 변경하지 않았다. HTC 경로는 `__UNSUPPORTED_HTC__`로 별도 표시한다. 공열분해 혼합비가 기존 v23 입력 feature에 없어 예측에서 반영되지 않는 한계가 있다.
- Stage 2: Phase 8 기존 98행으로 Model A(XGBoost), Model B(Ridge)를 **각 한 번 학습**하고, 신규 poultry-manure DOI의 물질수지 통과 51행을 외부 스트레스 테스트했다. 원료·제조경로·100 g/L 투입량으로 인한 분포 이동이 큰 조건이며, 이 51행은 **학습 승인되지 않았고** 측정된 수용액에서의 금속 제거에 침전이 기여했을 가능성이 있다.
- 포멜로 18행은 사용자 확인 단위 정정이 기록됐어도 초기 pH 미확정으로 기존 Stage 2 A/B 입력계약 미충족. 물질수지 초과 poultry 3행도 제외. 신규 총 72행 중 평가 대상 51행, 신규 학습 편입 **0행**.
- 소수 DOI 및 불균질 target이므로 전체 R²는 설명 참고치로만 보고하며, 특정 외부 DOI에서 안정적 일반화가 확보됐다고 주장하지 않는다.

## Stage 1 결과 — 외부 6 DOI / 33시료

| 평가 | BET MAE (m²/g) | TPV MAE (cm³/g) |
|---|---:|---:|
| 전체 33행 (HTC/개질/공열분해 포함, **OOD 혼재**) | 152.61 | 0.0687 |
| 단일 건식 열분해 17행 | 114.41 | 0.0649 |

신규 원료 BET의 상당수가 낮은 범위(일부 1–30 m²/g)인데, 기존 고정 비교 모델은 수십~수백 m²/g으로 과대예측했다. **구성비가 다른 공열분해 시료가 같은 온도에서 동일한 값으로 예측되는 사례**도 있는데, 혼합비가 해당 모델의 feature가 아니기 때문이다. 일반 열분해만 따로 평가해도 오차가 크며, 온도·시간·대상 원료만으로는 신규 저BET 원료를 충분히 구분하지 못한다는 근거다.

단, route mapping은 모델의 기존 입력 구조에 맞춘 *연구용 사상*이지 원문이 직접 보고한 동일 변수가 아니다. 따라서 배포 v60 성능과 같다고 하면 안 된다. 후속 과제는 raw-feedstock composition, inorganic/ash, 공정 경로·혼합비를 검증 가능한 동일 DOI 단위 학습·평가로 반영하는 것이다.

## Stage 2 결과 — 1 신규 DOI / poultry 51행 (독립 일반화 주장 불가)

| 지표 | A (XGBoost) | B (Ridge) |
|---|---:|---:|
| raw MAE (mg/g) | 67.85 | 1,143.83 |
| 원시 물질수지 제약 위반 | 51/51 (100%) | 51/51 (100%) |
| 위반 종류 | 전부 상한 초과 | 전부 음수 |
| clipping 후 MAE (mg/g) | 0.01514 | 3.20839 |
| **단순 상한 baseline (`q=C0/dose`) MAE** | **0.01514** | **0.01514** |

**해석의 핵심:** A의 51개 원시값이 전부 상한보다 커서 clipping 후 결과는 51개 전부 `q=C0/dose`가 된다. clipping된 A의 MAE 0.01514는 별도 모델의 흡착 메커니즘 설명력이 아니라 **물질수지 상한 baseline과 완전히 같은 산출물**이다. 이 값을 모델 우수성 근거로 사용하면 안 된다. B는 51개 모두 음수이므로 clipping하면 전부 0이 된다.

모델 학습에서 흡착제 투입량 최대는 10 g/L, 신규 논문은 100 g/L. 새 오염물질 Zn(II)는 모델 학습 98행에 존재하지 않는다. 가금분의 최종 pH 상승과 침전 위험도 원시 모델 target 분포와 다른 문제다. 현 배포 모델의 현장 적용 실패율을 추정하는 평가가 아니라, **적용범위 밖 입력에 대한 스트레스 테스트**로 봐야 한다.

## v24 신규 자료 정리의 중요 한계

- v24 Stage 1 신규 33행에는 원료 자체의 `raw_C/H/O/N/Ash` 조성 값이 직접 채워져 있지 않다. 별도 `raw_feedstock_composition_PARTIAL_BASIS_UNVERIFIED.csv`에 가금분·면화줄기의 **부분 조성 2원료**가 있으나, 분석 basis 및 혼합 조성 해석을 확인하기 전에는 feature에 복사하면 안 된다.
- 새 Stage 1 33행은 모두 열분해 전 원료 VM/FC 자료가 없다.
- 포멜로 SI의 mmol/g→μmol/g 수정은 사용자 제공 사실로 기록(출판사 정오표 미확인). 원문 수치와 정정 가정을 모두 추적해야 한다.
- Stage 2 reported uptake는 엄격 평형 qe로 자동 재분류하지 않는다. qmax는 별도 target 유지.

## 권고

1. **배포 모델 동결 유지.** v24 추가 data를 자동으로 모델 재학습에 사용하지 않는다.
2. v24 이후 데이터 수집은 (a) **열분해 전** raw VM/Ash/FC와 CHON의 basis, (b) 같은 제조시료 BET·TPV와 초기 pH가 포함된 흡착실측값, (c) 혼합비·활성화 처리 조건, (d) 침전/흡착 구분이 가능한 논문을 우선한다.
3. Stage 1의 **같은 DOI 분할**과 Stage 2 A/B의 물리 baseline을 유지하면서 Input feature 보완 가설을 사전 지정하고 검증한다.
4. 제조조건 추천은 아직 신규 원료 전역 최적화로 표현하지 않는다.
