# v58 연구 보고서 — 신규 DOI 전이 실패의 원인과 물질수지 입력 특성 검증

작성: 2026-10-31. 근거: v47 통합 프로젝트에 누적된 v55–v57 실측/원문 기록, v57 OOF 및 source-out 예측, v58 실제 재학습. **연구용 탐색적 분석이며 배포 모델 변경 없음.**

## 핵심 결론

1. **Shen 29행은 서로 독립적인 29개 제조시료가 아니라 단일 DOI의 바이오차 4개에 대한 농도별 흡착등온선 자료**다. 이 DOI의 비중이 커지면서 기존 DOI 일부의 오차가 증가했다. 관측 행 수 확대와 독립적인 소재 종류 확대를 혼동하지 않는다.
2. 기존 Model A/B는 `C0_mg_L`와 `dose_g_L`를 별도 변수로 갖지만 물질수지 상한 `C0/dose`를 명시적으로 입력하지 않는다. 신규 Shen source-out에서 기존 Model A는 29행 중 21행, B는 25행의 예측값이 상한까지 clipping되었다. 이는 새 논문의 흡착량 차이를 식별하지 못한 징후다.
3. **Model B에 물질수지 상한을 입력하면** 기존 v55 152행 학습 기준 140행 DOI 5-fold 평가 MAE가 17.5296 → **16.5472 mg/g**, Shen DOI source-out MAE가 10.1857 → **6.2641 mg/g**으로 줄었다. 하지만 이전부터 해당 DOI가 반복적인 모델 선택에 사용되었으므로 사후 탐색적 결과다. DOI bootstrap 95% 개선구간은 **−2.167~+4.104 mg/g**으로 0을 포함한다.
4. **물리 특성 입력이 제조조건 추천 문제를 해결하지는 않는다.** Chen 2022의 16조건에서 Model B cap 예측은 **12개 조건에 동일하게 제거율 100%**를 제시했다. 기존 평가 함수는 전체 예측값이 같을 때만 동률로 처리하여 일부 최상위 동률을 감지하지 못했다. strict top-1 regret은 NA로 재판정하며 공동 1위 내 regret 가능 범위는 **0~68.92 %p**다.
5. v57 새 36행을 모두 추가한 상태에 cap/log(cap) 특성을 추가해도 기존 140행에서 Model B MAE는 **16.8123 mg/g**으로, v55 152행에 cap만 추가한 **16.5472 mg/g**보다 높다. 원문 36행은 계속 보존하되 학습 적격 가중치·적용영역은 구분해야 한다.

## 1. 데이터 구조와 분포 차이

- 기존 Stage2 평가 정본: 140행, 32 DOI. 기존 각 DOI 관측 수 중앙값 3행(최대 13행).
- Shen et al. (2017), DOI 10.1007/s11356-017-8847-2: Ni(II) 29행, 4개 고유 바이오차, pH 5, dose 5 g/L, 20°C, 24시간. 29행은 Figure 6 실험 흡착등온선 점 추출값으로, 논문 Methods의 nominal initial concentrations에 대응시킨 값이다. 원문 그림의 가로축은 평형농도 `Ce`이므로, 각 추출 점과 nominal `C0`의 일대일 매칭은 원시 측정표가 없는 한 추가 감사 대상으로 남긴다. 출처: 제공 원문 PDF pp.3, 7–8; Figure 6.
- Cao et al. (2019), DOI 10.1016/j.scitotenv.2019.07.102: Pb(II) 7행, 제조온도 300–900°C의 별도 바이오차 7개, dose 0.6 g/L, C0 100 mg/L. Table 2의 48시간 `qTotal`은 평형 독립증명이 남아 있는 실험 관측으로서 strict-qe 확정 자료와 별도 구분. 제공 원문 p3 및 Table 2.
- Shen 29행의 중앙 `qe/(C0/dose)`는 **0.8777**, Cao 7행은 **0.7475**다. 기존 140행은 중앙 **0.7260**. Shin(Shen) 계열의 낮은 농도에서 cap이 작은데도 기존 회귀기가 높은 흡착량을 예측하여 값이 상한으로 절단되는 문제가 관찰된다.
- Stage2 B의 제조조건 입력: 두 신규 DOI 모두 유지시간과 승온속도가 전부 NR이다. Model B는 BET/TPV를 직접 쓰지 않으므로 이 데이터의 물성 결측을 B 성능 악화의 직접 원인이라고 단정하지 않는다. 다만 제조 공정 변수를 회복하지 못해 조건 간 차이를 학습하기 어렵다.

## 2. 새 36행 추가 후 기존 DOI 중 성능 악화

공통 평가: 원래 140행·32 DOI, GroupKFold 5-fold, train fold 전처리 적합, 추가 DOI가 평가 DOI와 겹치지 않도록 제외, 예측 후 `0≤qe≤C0/dose` clipping. 기존 DOI를 모델 튜닝과 분석에 반복 사용했으므로 성능 추정은 탐색적이다.

| 오염물질 | 평가 n | Model B 기존 152 MAE | Model B 신규 36 전부 포함 MAE |
|---|---:|---:|---:|
| Cd(II) | 67 | 8.824 | 10.816 |
| Cu(II) | 31 | 17.885 | 20.528 |
| Ni(II) | 12 | 29.855 | 34.638 |
| Pb(II) | 14 | 40.834 | 44.709 |
| Zn(II) | 6 | 26.486 | 33.372 |
| Phenol | 10 | 21.961 | 18.786 |

Model A 전체 MAE 16.5877 → 18.7916, Model B 17.5296 → 19.9340 mg/g. Model B에서 32 DOI 중 **17개 악화, 11개 개선, 4개 변화 없음**으로, 한 논문만의 문제라고 보기 어렵다. 그러나 악화량 합계의 약 56.7%가 상위 3개 기존 DOI에 집중돼 있다. 행별 및 DOI별 오차 변화는 동봉 CSV 참조.

## 3. `C0/dose` 특성 추가 검증

Model A/B 원래 XGBoost 구조·파라미터는 유지하고 `physical_cap_mg_g`와 선택적인 `log1p(physical_cap_mg_g)`만 사전 입력 변수에서 계산해 추가했다. 실측 `qe`, `Ce`, `qmax`, 제거율은 입력으로 사용하지 않았다.

| 모델 | 학습 구성 | 입력 | 공통 140행 MAE | clipping 이전 cap 초과 (140행) |
|---|---|---|---:|---:|
| A | v55 152행 | 기존 | 16.588 | 42 |
| A | v55 152행 | cap | **16.499** | 27 |
| A | v57 188행 | cap+logcap | 17.566 | 19 |
| B | v55 152행 | 기존 | 17.530 | 43 |
| B | v55 152행 | cap | **16.547** | 35 |
| B | v57 188행 | 기존 | 19.934 | 원본 v57 CSV 참조 |
| B | v57 188행 | cap+logcap | 16.812 | 22 |

- B(v55 152 + cap) vs 기존 B(v55 152)의 paired DOI bootstrap 개선량 95% 구간: **−2.167~+4.104 mg/g**. 0을 포함함. 이 값은 사후 탐색 비교의 불확실성 참고치이지 확증적 유의성 검정은 아니다.
- A/B는 **물질수지 상한 위반을 clipping 전에도 계속 생성**한다. 입력 cap 추가와 출력물리보장은 별개의 문제다.

### 사후 신규 DOI source-out (학습에 시험 DOI 없음)

| 시험 DOI | 모델 | 기존 Model | v55 + cap 입력 | 0 예측 기준 MAE |
|---|---|---:|---:|---:|
| Shen Ni(II) 29행 | A | 10.063 | 9.213 | 8.403 |
| Shen Ni(II) 29행 | B | 10.186 | **6.264** | 8.403 |
| Cao Pb(II) 7행 | A | 61.382 | 51.939 | 118.951 |
| Cao Pb(II) 7행 | B | 80.659 | 65.441 | 118.951 |

Cao는 기존 A가 모든 제조온도에 동일한 값을 예측한다. **A는 원천적으로 제조조건 변수를 갖지 않으므로** 동일 흡착조건 하 제조온도 순위를 매길 수 없다. B에 cap을 추가하면 예측값은 7개 중 일부가 구분되지만 800°C와 900°C가 공동 최상위다. 이 경우 strict Top-1은 정할 수 없고 가능한 regret 범위는 0–5.12 mg/g이다.

## 4. Chen 16조건 재평가: 최상위 동률 감지 오류 교정

- 기존 v55 152행 Model B: Spearman ρ=0.443, 단독 최고값은 실제 최적과 달라 **top-1 regret 65.55 %p**.
- 신규 `cap` Model B: Spearman ρ=0.582이지만, **12/16개 조건이 100% 예측으로 공동 1위**. 따라서 strict Top-1 regret = **NA**, 가능한 regret = **0~68.92 %p**.
- 논문의 해당 조건 비교에서 실험 pH는 NR로 유지되어 결측 대체가 작동했다. 또한 평가 논문은 개발 과정에 반복 사용됐으므로 독립성 없음. 순위 상관이 올랐다는 이유만으로 추천 기능을 승인할 수 없다.
- Model A는 제조조건 자체를 입력받지 않으므로 16개 조건을 동일하게 예측하고, 독립적인 제조조건 추천에 구조적으로 부적합하다.

## 5. 다음 연구 우선순위 (데이터는 누적 보존)

1. **라벨 계보 구분 유지:** 실험 평형 `qe` / 48시간 `qTotal` / `qt` / Langmuir `qmax` / figure digitized / source-derived C0를 별도 컬럼으로 저장. 특히 Shen Figure 6에서 `Ce` 그래프의 점과 nominal `C0` 배정 근거를 추가 확인.
2. **독립 실험단위 가중:** 관측 29행을 29개의 독립 제조시료로 취급하지 않고 `DOI→시료→농도` 계층을 모델링. 기존 v57의 Shen weight 0.1 실험으로도 이 문제는 완전히 해결되지 않았으므로 단순 가중치만 반복 튜닝하지 않음.
3. **타깃·농도 영역 분리:** 논문별 `C0`, dose, cap, pollutant, 원료가 학습 범위에 있는지 점검하고, 학습 시 특히 희박한 Ni 및 고흡착 Pb의 별도 진단을 진행.
4. **예측과 순위 분리:** qe 예측에는 파생 cap 특성을 후보로 유지하되 추천에는 공동 1위·상한 포화 여부를 필수 경고. 온도·시간 등 제조특성이 실제로 구분되는 Model B만 후보.
5. **다음 완전히 새로운 DOI는 봉인 평가:** 미래 평가용 후보는 기존 이력에서 미노출된 DOI 및 참조 시료 확인 후 모델을 고정하고 1회 평가. 동일 140행에 여러 번 최적화한 결과를 확인적 일반화 성능으로 표기하지 않음.
