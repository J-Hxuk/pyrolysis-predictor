# v59 — DOI·제조시료 계층 가중치 재학습: 실제 실행 결과

**범위:** 2026-10-31. v58의 학습 모델 A/B와 사전 입력 `C0/dose`를 유지하고, 학습 가중치만 바꾼 연구용 사후 실험. 기존 승인 DB 및 활성 모델은 수정하지 않았다.

## 연구 질문과 실험 설계

Shen 2017의 29개 관측은 제조시료 4개의 초기농도별 측정이다. 29개의 독립적 소재로 가정하여 동일가중을 부여하면 논문 내 반복 관측이 학습을 과도하게 지배할 수 있다. 188행에서 Shen DOI의 행 점유율은 29/188=15.43%다.

- **학습군:** v55 152행(기존 140 + 사과나무 8 + Sugarcane 4) 및 v57 188행(+ Shen 29 + Cao 7)을 별도로 평가.
- **평가군:** 기존 140행·32 DOI 고정. 동일 5-fold GroupKFold DOI 분할에서 모델 A/B, baseline/cap 입력을 비교. 평가 DOI 전체는 각 fold의 학습·가중치 계산에서 제외.
- **가중치 정책:** (1) 관측행 동일, (2) DOI 표본 수의 제곱근에 비례, 논문 내 행 동일, (3) DOI 제곱근 + 동일 논문 내 제조시료 균등, (4) DOI·제조시료 완전 균등. 각 fold의 학습 sample_weight 평균을 1로 정규화.
- DOI g의 전체 행 수가 n_g, 제조시료 m의 행 수가 n_gm일 때, 각 행의 정규화 전 가중치는 `n_g**alpha * n_gm**beta / (sum_m n_gm**beta) / n_gm`. (alpha,beta) = (1,1), (.5,1), (.5,0), (0,0).
- **가중치에 사용한 변수:** DOI와 제조시료 식별자뿐. qe나 오염물질별 오차를 보면서 각 행의 가중치를 계산하지 않음.

**제조시료 그룹 감사:** 기존 140행 중 `material_uid`가 비어 있던 27행은 Wang 2019 12행, Hu 2022 3행, V38 12행의 관측 ID에 나타난 제조조건 접두부를 이용해 분석용 그룹을 추출했다. 원문 제조 배치까지 동일하다고 검증한 것은 아니며 전체 매핑을 `material_id_mapping_audit.csv`에 기록했다.

## Stage2 Model B + `C0/dose` 입력: 같은 140행 평가

| 가중치 | v55 152행 MAE (mg/g) | v57 188행 MAE (mg/g) |
|---|---:|---:|
| 기존 행 동일 | 16.547 | 17.124 |
| DOI 제곱근, 행 동일 | 16.122 | **16.175** |
| DOI 제곱근 + 제조시료 균등 | **15.892** | 16.289 |
| DOI·제조시료 완전 균등 | 16.392 | 16.387 |

152행의 DOI 제곱근+제조시료 균등 방식은 16.547 → **15.892 mg/g**로 MAE가 0.655 감소했으나, DOI cluster bootstrap 개선량 95% 구간은 **−0.945~+1.818 mg/g**로 0을 포함한다. 같은 자료로 여러 전략을 비교했으므로 확증적 향상 증거가 아니다.

188행의 DOI 제곱근(행 동일)은 17.124 → **16.175 mg/g**로 0.949 감소, DOI bootstrap 구간 **+0.084~+2.062 mg/g**였다. 그러나 이 방식 역시 사후 선정이므로 선택 편향을 고려해야 한다.

Model A의 가중치 효과는 일관되지 않았다. 예를 들어 v55 152행 baseline의 MAE는 16.588 → DOI 제곱근·시료균등에서 17.179로 악화됐고, v57 188행 cap 모델에서는 17.598 → 16.993으로 감소했다. 전체 32개 조합의 MAE, RMSE, DOI 평균 MAE, 물질수지 상한 위반은 CSV에 보존했다.

## DOI 점유율 및 유효 표본 수

188행 학습의 Shen DOI 가중치 비중은 **15.43% (행 동일) → 7.19% (DOI 제곱근) → 2.78% (DOI 완전 균등)**로 감소한다. 다만 중요도를 재분배하므로 Kish의 가중 유효 표본수 ESS는 대략 **188 → 156 → 94**로 감소한다. 관측을 삭제한 것이 아니다.

## 신규 DOI Source-out: 결과가 서로 다름

Model B + cap, v55 152행 학습. 각 논문 전체를 학습에서 제외하고 예측하되, 이미 연구자가 확인한 논문들이므로 **사후 Source-out**이다.

| 평가 논문 | 기존 행 동일 MAE | DOI 제곱근+제조시료 균등 MAE | 판단 |
|---|---:|---:|---|
| Shen Ni(II), 29행 | **6.264** | 11.498 | 악화 |
| Cao Pb(II), 7행 | 65.441 | **63.609** | 약간 개선, 절대 오차 큼 |

즉 기존 DOI의 평균 성능이 좋아지더라도 새로운 원료·논문의 예측이 좋아진다는 근거는 아니다. Cao의 MAE는 여전히 매우 크다.

## Chen 16개 제조조건 추천

Model B + cap, v55 152행에서는 기존 행 동일가중 모델이 **12개 상한 공동 1위**였고, DOI 제곱근+제조시료 균등에서는 **9개 공동 1위**였다. Spearman ρ가 약 0.582 → 0.721로 상승했더라도 **고유 1위를 추천할 수 없는 상황**은 해결되지 않았다. Chen 원문 일부 실험조건(pH)도 미보고이므로 엄격한 추천 실증은 아니다. 동률이면 `top1_id` 및 `regret_if_unique`를 비워둔다.

## 최종 연구 판단

- DOI·제조시료 가중치를 바꾸면 **일부 Stage2 Model B MAE는 낮아진다.** 특히 152행 B+cap은 15.892 mg/g를 기록했다.
- **하지만 새 DOI 예측 개선은 일관되지 않았고** 제조조건 추천 동률도 남아 있어 활성 모델 승격은 보류한다.
- 연구용 모델 **6개**를 별도 저장: 사전 정의된 188행 A/B × baseline/cap 4개, 사후 탐색용 B 152행 cap 및 B 188행 cap 2개. 후자의 수치는 모델 선택에 사용된 기존 140행에 대한 사후 결과라는 점을 메타데이터에 남겼다.
- 기존 자료 및 활성 모델은 변경하지 않았다. 데이터·모델 SHA256, 사용 환경과 피처 계약은 `run_manifest.json`에 있다.
- 프로젝트 Python 3.13.5, scikit-learn 1.8.0, XGBoost 3.1.3 환경에서 **기존 47개 + 신규 6개 = 53개 테스트 통과**. Windows 기존 가상환경의 scikit-learn 1.5.2에서는 결과가 달라질 수 있어 같은 코드로 현지 재학습·OOF 재계산이 필요하다.
